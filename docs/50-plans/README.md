# 50 — План реализации

План реализации Praxis **целиком**: от каркаса до публичного релиза. Каждая задача ссылается на требования и спеки, которые она выполняет, поэтому по любой задаче видно, *зачем* она и *чем* проверяется ([правила DocDD](../README.md#правила-docdd)).

План пересобран 2026-09-30 при переходе на DocDD ([ADR-0018](../40-adr/0018-phase-renumbering.md)). Фазы 0–2 закрыты: для них план фиксирует, что сделано и чем доказано, а задачи, отмеченные сделанными без реализации, переоткрыты. Прежние чеклисты с подробными доказательствами — в [archive/](./archive/).

## Формат задачи

Задача — строка таблицы в плане фазы:

| Поле | Содержание |
|---|---|
| **ID** | `P<фаза>-<поток>-<NN>`. Поток — независимая дорожка внутри фазы. ID не переиспользуется |
| **Задача** | Что сделать, одним-двумя предложениями, с наблюдаемым результатом |
| **Трассировка** | `FR-…` / `NFR-…` и `SPEC-NN` (`AC-NN.n`), которые задача закрывает. Для инфраструктуры — только `NFR` |
| **Статус** | ⚪ todo · 🟡 wip · 🟢 done · 🔴 blocked (чем) · ⚫ dropped (почему) |
| **Проверка** | Вид доказательства: *live* / *test* / *build* / *device* — и где оно зафиксировано |

## Порядок работы над задачей

1. Взять задачу, у которой закрыты зависимости. Если спека в статусе `draft`, сначала довести её до `approved`: уточнить контракт и AC.
2. Если по ходу принимается решение — оформить ADR до кода.
3. Сделать код и тесты; прогнать обязательные проверки (NFR-13).
4. Доказать AC видом проверки, который требует спека. Клиентская фича закрывается только после *live* или *device*.
5. В том же изменении обновить: статус задачи здесь, статусы AC и «Расхождения» в спеке, статус требования, строку в журнале [ROADMAP](../../ROADMAP.md).

## Definition of Done фазы

Фаза закрыта, когда:

1. Все задачи 🟢 или ⚫ с причиной.
2. Критерий выхода фазы выполнен и доказан.
3. Инварианты проверены (скрипт инвариантов с Ф3; до этого — ручной прогон).
4. **Сверка документации с кодом**: спеки фазы не содержат устаревших «Расхождений», статусы требований совпадают со статусами задач (NFR-19).
5. В журнале ROADMAP — запись о закрытии с видами проверки.
