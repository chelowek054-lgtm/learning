## Проверки конца фазы

- [ ] Приложение установлено из стора и проходит сквозные сценарии Ф1–Ф5.
- [ ] Прод поднимается из `main` с миграциями; dev-секреты запрещены.
- [ ] Политика данных опубликована, согласие фиксируется, сроки исполняются кодом, удаление аккаунта работает.
- [ ] Код восстановления приходит письмом; в БД — хеш; сессии отзываются.
- [ ] Повторения на двух устройствах сходятся.
