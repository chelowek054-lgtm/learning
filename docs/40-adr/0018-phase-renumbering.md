# ADR-0018 — Перенумерация фаз: укрепление фундамента перед речью

| | |
|---|---|
| **Статус** | `accepted` |
| **Дата** | 2026-09-30 |
| **Затрагивает** | 50-plans, ROADMAP |

## Контекст

При переходе на DocDD сверка документации с кодом нашла долги, которые мешают следующей фазе:

- клиент ни разу не запускался на устройстве;
- на backend нарушен инвариант доменной независимости;
- прогресс FSRS не синхронизируется;
- нет CI;
- учёт токенов отмечен сделанным, но отсутствует.

Прежняя Фаза 3 (речь) начиналась с потока WS0 «прогон на устройстве», и эти долги в него не помещались.

## Решение

План перестроен в 7 фаз:

| Новая | Содержание | Было |
|---|---|---|
| Ф0 | Каркас | Ф0 |
| Ф1 | MVP | Ф1 |
| Ф2 | Модель знаний | Ф2 |
| **Ф3** | **Укрепление фундамента**: устройство, CI, инварианты, sync, стоимость, долги графа | WS0 прежней Ф3 + долги |
| Ф4 | Речь и рецепция | Ф3 (WS1–WS6) |
| Ф5 | Расширение обучения: код, импорт, Task 1, TOEFL, языковой граф, прогресс | части исходной «Адаптивности» и Ф4 |
| Ф6 | Продукт и релиз | Ф4 |

ID задач закрытых фаз (P0–P2) сохранены. Задачи прежней Ф3 получили префикс P4: `P3-WS1-01` → `P4-WS1-01`.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Оставить Ф3 речью, долги — в WS0 | Номера не меняются | Фаза речи начинается с десятка несвязанных задач |
| Отдельная фаза укрепления | Чистые входные условия для речи | Номера фаз после Ф2 сдвигаются |

## Последствия

«Фаза 3 — речь» в истории коммитов и в архиве относится к прежней нумерации. Архив — [50-plans/archive](../50-plans/archive/).
