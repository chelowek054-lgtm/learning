# ADR-0006 — Expo SDK 54 ради совместимости с публичным Expo Go

| | |
|---|---|
| **Статус** | `accepted` |
| **Дата** | 2026-07-04 |
| **Затрагивает** | NFR-20 |

## Контекст

Проект создан на SDK 57. Публичный Expo Go в сторах отстаёт, и без собственной сборки открыть на телефоне проект на новом SDK нельзя.

## Решение

Клиент понижен до **Expo SDK 54** (React Native 0.81, React 19.1, TypeScript 5.9), чтобы запускать его в публичном Expo Go без EAS-сборки.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Остаться на 57 и собрать dev-client | Свежий SDK | До первого запуска нужна EAS-сборка |
| SDK 54 | Запуск в Expo Go сразу | Отставание от актуального SDK |

## Последствия

Перед публикацией (Ф6) клиент переходит на dev-client и EAS Build. Тогда SDK можно поднять отдельным ADR.
