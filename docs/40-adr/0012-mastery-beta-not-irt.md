# ADR-0012 — Освоенность — бета-модель с приором из предпосылок, не IRT

| | |
|---|---|
| **Статус** | `accepted` |
| **Дата** | 2026-08-23 |
| **Затрагивает** | SPEC-10 |

## Контекст

Плейсменту нужна оценка освоенности узла по нескольким ответам. Калиброванных заданий нет: они генерируются.

## Решение

Освоенность узла — бета-распределение (`alpha`, `beta`), скаляр на узел плюс достигнутая ступень Блума.

- **Приор** берётся из предпосылок: `min(оценки) × 0.70`, у корня 0.20; сила приора — 2 виртуальных ответа.
- **Обновление** байесовское, по `score` 0..1.
- **Уверенность** считается по объёму свидетельств, `n/(n+3)`, а не по разбросу распределения.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| IRT | Точность, калибровка заданий | Нужны данные калибровки, которых нет |
| Бета-модель | Работает без калибровки, объяснима | Не учитывает сложность задания |

## Последствия

Живой прогон нашёл два дефекта, оба исправлены:

1. Уверенность, считавшаяся по разбросу, росла от ответа, противоречащего приору.
2. Аддитивный приор делал глубокие узлы «вероятнее известными».

Переход на IRT — после накопления данных, отдельным ADR.
