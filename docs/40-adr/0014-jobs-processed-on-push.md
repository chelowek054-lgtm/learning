# ADR-0014 — AI-задачи исполняются синхронно на `/sync/push` (до появления воркера)

| | |
|---|---|
| **Статус** | `accepted` |
| **Дата** | 2026-07-04 |
| **Затрагивает** | SPEC-03 |

## Контекст

Для MVP нужна очередь AI-задач, но фоновой воркер (Celery, RQ, отдельный процесс) несоразмерен объёму.

## Решение

Сервер обрабатывает `pending`-jobs пользователя синхронно внутри запроса `/sync/push`. Результат клиент получает в том же sync через pull. Для ручного запуска есть `/jobs/process`.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Фоновой воркер | Не блокирует запрос, масштабируется | Отдельный процесс и брокер |
| Синхронно на push | Ноль инфраструктуры | Долгие задачи упрутся в таймаут запроса |

## Последствия

Подходит для оценки текста, которая занимает секунды. STT и генерация аудио (Ф4) в таймаут не уложатся, поэтому перед ними нужен ADR о воркере (P4-WS2-03). Повторов с отсрочкой пока нет (P3-SYNC-04).
