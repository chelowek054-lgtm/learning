# ADR-0005 — Raw `expo-sqlite` за портом `LocalStore` вместо Drizzle; web — in-memory

| | |
|---|---|
| **Статус** | `accepted` |
| **Дата** | 2026-07-04 |
| **Затрагивает** | SPEC-03 |

## Контекст

Исходный план предполагал Drizzle ORM. Но миграции Drizzle требуют codegen и настройки Metro под `.sql`, а проверить это без устройства было нельзя. На web `expo-sqlite` тянет `wa-sqlite.wasm`, которому нужны COEP и OPFS.

## Решение

SQLite используется напрямую (`CREATE TABLE IF NOT EXISTS`, синхронный API) за портом `LocalStore` из ядра. На web работает платформенная замена `sqlite-local-store.web.ts` — хранилище в памяти.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Drizzle | Типобезопасные миграции | Codegen и Metro-конфиг, непроверяемо без устройства |
| WatermelonDB | Готовый sync | Навязывает свою модель синхронизации |

## Последствия

Замена хранилища затрагивает только адаптер, ядро не меняется. На web данные теряются при перезагрузке вкладки — это приемлемо, потому что web служит инструментом разработки, а не целевой платформой. Эволюция схемы на устройстве понадобится с первым изменением локальной схемы (P3-SYNC-02).
