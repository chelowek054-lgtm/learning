# ADR-0016 — Пустую область строит выбравший предмет; узлы — draft до вычитки

| | |
|---|---|
| **Статус** | `accepted` |
| **Дата** | 2026-08-25 |
| **Затрагивает** | SPEC-08, NFR-KG-6 |

## Контекст

После перехода к свободному выбору предмета новый предмет оказывался тупиком: карты нет, а строить канон мог только администратор.

## Решение

`/graph/canon/build` открыт любому пользователю, **пока в домене нет ни одного узла**. Достраивать область и делать `refresh` может только администратор.

Построенные узлы получают `status='draft'`. В графе это поле `reviewStatus`, в интерфейсе — метка «не проверено». Куратор вычитывает узлы и подтверждает их через `approve`.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Строит только администратор | Канон всегда курирован | Новый предмет — тупик |
| Любой строит пустую область | Предмет работает сразу | В каноне появляются непроверенные узлы |

## Последствия

Непроверенный контент увидят все, кто выберет тот же предмет. Метка «не проверено» честно об этом сообщает.
