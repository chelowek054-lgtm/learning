# ADR-0008 — uv для Python-окружения backend

| | |
|---|---|
| **Статус** | `accepted` |
| **Дата** | 2026-07-04 |
| **Затрагивает** | — |

## Контекст

На Ф0 оставался открытым вопрос: poetry или uv.

## Решение

Backend — проект на **uv** (Python 3.12), `uv.lock` лежит в репозитории. В Docker-образ `uv` ставится **из PyPI**, а не копируется из `ghcr.io/astral-sh/uv`: демон Docker в среде разработки не достаёт `ghcr.io` (TLS handshake timeout).

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| poetry | Привычно | Медленнее, отдельный формат lock |
| uv | Быстро, один инструмент | Моложе |

## Последствия

Установку uv в образе нельзя «оптимизировать» обратно на ghcr.io ([HANDOFF §3](../HANDOFF.md#3-грабли-этой-среды)).
