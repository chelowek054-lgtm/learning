## Назначение

Быстро понять, где учащийся находится в графе, чтобы курс не начинался ни с известного, ни с непосильного.

## Поведение

1. **Цель.** Учащийся выбирает целевой уровень (ступень Блума) — это потолок зондов. На экране уровни названы по-человечески: «узнаю термины», «объясню своими словами», «решу задачу», «построю своё».
2. **Приор.** Освоенность узла без наблюдений выводится из предпосылок (`prereq`/`specializes`). Корень получает 0.20. Остальные узлы — `min(оценки предпосылок) × 0.70`: берётся минимум, потому что одной неосвоенной предпосылки достаточно, и связь условная, а не аддитивная. Границы 0.02–0.95, сила приора — 2 виртуальных ответа.
3. **Выбор зонда.** Кандидаты — узлы на границе (предпосылки освоены) с пригодной теорией. Ранг = неопределённость × (1 + 0.5 × centrality). Ступень зонда — минимум из цели и доступных ступеней узла.
4. **Ответ.** Оценивается по [SPEC-09](./SPEC-09-assessment.md). Бета-обновление: `alpha += score`, `beta += 1 − score`, `observations += 1`. При `score ≥ 0.6` растёт `bloom_reached`.
5. **Уверенность** — по объёму свидетельств: `n / (n + 3)`. Узел `known`, если `estimate ≥ 0.75` и `confidence ≥ 0.6`.
6. **Остановка** с кодом причины:
   - `empty` — в домене нет узлов (нужно построить граф);
   - `no_theory` — на границе нет узлов с теорией;
   - `settled` — на границе не осталось неопределённости выше 0.4.
7. **Итог** — карта: `known` / `frontier` / `learning` / `locked` по узлам.

## Контракт

| Метод | Путь | Вход | Выход |
|---|---|---|---|
| GET | `/graph/placement/{domain}/probe?target=` | — | `{conceptId, conceptTitle, conceptVersion, bloom, cached, priority, uncertainty, item}` или `{done, reason, code, map}` |
| POST | `/graph/placement/answer` | `{domain, concept_id, bloom, answer}` | `{conceptId, score, explanation, mastery, next}`; при остановке `next=null, done, reason, code` |
| GET | `/graph/placement/{domain}/map` | — | `{domain, nodes: [{conceptId, title, tier, centrality, status, …mastery}], summary: {status: count}, coreCovered}` |

`user_concept.mastery`: `{alpha, beta, estimate, confidence, bloom_reached, observations}` (производные поля пишутся для клиента).
