## Назначение

Одна-две фразы: какую задачу человека или системы закрывает возможность и почему она нужна (ссылка на `00-product`).

## Поведение

Сценарий глазами пользователя и системы: шаги, ветки, крайние случаи. Без деталей реализации, которые не видны снаружи.

## Контракт

API (метод, путь, вход, выход, коды ошибок), модель данных, события, форма `payload`. Только то, на что опираются другие части системы.
