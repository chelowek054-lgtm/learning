## Назначение

Интерфейс говорит от задачи человека, а не от модели системы: человек всегда знает, что делать сейчас и зачем ([personas](../00-product/personas.md#учащийся)).

## Поведение

1. **Онбординг** (после регистрации, пока не выбран предмет): поле «что изучаете» (свободный текст) и целевой уровень из четырёх формулировок. Сохраняется в `profile.subject = {id: slug(title), title, target}`. Slug сохраняет юникод; в URL он кодируется слоем `api`.
2. **Предмет** читается экранами через `useSession().subject`; строк вида `'ml'` в экранах нет.
3. **«Сегодня»** показывает **одно** действие с причиной. Приоритет (`nextAction`):
   1. нет предмета → выбрать предмет;
   2. есть текущий шаг курса → шаг, причина из `StepReason`;
   3. есть карточки к повторению → повторение;
   4. иначе → плейсмент.
   Сырой список активностей вынесен на служебный роут `/activities`.
4. **Словари** — единственные источники: названия типов (`ActivityTypeDef.title/hint`), уровни (`MASTERY_TARGETS`), причины шагов (`STEP_REASON`). Новый экран спрашивает словарь, а не заводит свою карту.
5. **Граф**: учащийся видит карту на чтение (`GraphMap`), администратор — курирование (`GraphCuration`); выбор по `isAdmin`. Пустая карта предлагает построить себя ([ADR-0016](../40-adr/0016-empty-domain-built-by-learner.md)); узлы `draft` помечены «не проверено».
6. **Тема**: системная, светлая или тёмная. Все цвета, кегли и отступы — в `shared/config/design.ts`.
7. **Прогресс** (цель, `FR-UX-07`): экран с метриками из [metrics.md](../00-product/metrics.md) — удержание, рост по рубрикам, положение границы относительно цели.

## Навигация

Вкладки: «Сегодня» (`index`), «Курс», «Граф», «Профиль». Отдельные роуты: `review`, `placement`, `activities` (служебный). Роуты в `src/app` тонкие: реэкспорт экрана из `pages`.
