# Требование: проверка предварительных знаний перед построением курса

После подтверждения цели:

1. Модель называет обязательные базовые области для цели (граф областей уже есть: «нужно знать до», уровень примитивности).
2. Человек проходит **короткий тест по этим областям**, сверху вниз по цепочке: освоенная верхняя ступень снимает нижние (механизм `chain_placement`, T-0066).
3. Результат записывается как освоенность человека (профиль), а не как изменение графа.
4. Ответы теста сверяются с нашим графом: по каждой нужной области определяется, есть ли в графе подтверждённые группы знаний и какого объёма (см. «Требование: поиск источников и разбор их в граф»).

## Критерии готовности

- Тест короткий и не блокирует: его можно пропустить (тогда считаем «не знаю»).
- По итогам формируется список областей: «хватает в графе», «мало», «нет».
- Проверка работает по графу областей, а не по списку, заданному вручную.

## Не выяснено

- Сколько вопросов на область и как не разрастить тест при длинной цепочке областей.
