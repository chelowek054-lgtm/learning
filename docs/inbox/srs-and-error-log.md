# Интервальное повторение и error-log

## Зачем

Удерживать факты и понятия интервальным повторением и связать его с продукцией: ошибки становятся карточками (vision).

## Состояние

частично — FSRS, error-log, колода по предмету и синхронизация работают; типы SRS ещё разошлись

## Как должно вести себя

1. **Повторение.** Экран повторения берёт карточки с `due_at ≤ now` из локального хранилища. Учащийся видит лицевую сторону, открывает оборот и отвечает again/hard/good/easy. `Scheduler.review` (ts-fsrs) пересчитывает `fsrs_state` и `due_at`. Сеть не нужна.
2. **Источники карточек** (`source`):
   - `awl` — стартовая колода Academic Word List при регистрации;
   - `error_log` — ошибки из `grade.errors` после оценки продукции; слабый ответ на шаге курса;
   - `generated` — карточка удержания узла при старте шага курса;
   - `imported` — зарезервировано для импорта (SPEC-16).
3. **Error-log.** Каждая ошибка `{kind, excerpt, correction, explanation}` становится карточкой: лицевая сторона «Исправь: «excerpt»», оборот — исправление и объяснение.
4. **Привязка к графу.** Карточка по узлу несёт `concept_id`; одна карточка удержания на узел.
5. **Стартовая колода** зависит от предмета: при сохранении `profile.subject` языковой модуль (название содержит IELTS/TOEFL/English/англ…) создаёт AWL и пробное эссе. Остальные начинают с пустой колоды, которую наполняют курс и error-log. При регистрации контент не создаётся.

## Что система обязана обеспечить

- Учащийся повторяет карточки офлайн с оценкой again/hard/good/easy; интервалы считает FSRS на устройстве. Признак: Ответ меняет `fsrs_state` и `due_at` без сети. (Сейчас: реализовано; прежний номер — FR-SRS-01.)
- Учащийся видит очередь «к повторению сегодня». Признак: Очередь = карточки с `due_at ≤ now`. (Сейчас: реализовано; прежний номер — FR-SRS-02.)
- Ошибки из оценённой продукции становятся карточками (error-log). Признак: После оценки эссе с ошибками появляются карточки `source='error_log'`. (Сейчас: реализовано; прежний номер — FR-SRS-03.)
- Карточка может быть привязана к узлу графа. Признак: Слабый ответ на шаге курса создаёт карточку с `concept_id`. (Сейчас: реализовано; прежний номер — FR-SRS-04.)
- Стартовая колода соответствует выбранному предмету. Признак: Учащийся с предметом «Теория музыки» не получает колоду AWL. (Сейчас: реализовано; прежний номер — FR-SRS-05.)
- Тип SRS-активности один и одинаково объявлен на клиенте и на backend. Признак: Тип, который отдаёт шаг курса, объявлен в реестре и имеет рендерер. (Сейчас: принято, не начато; прежний номер — FR-SRS-06.)
