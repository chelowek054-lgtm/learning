Источники только с подходящей лицензией и видимость источников учащемуся

Зачем: учащийся должен иметь возможность перейти по ссылке и посмотреть место, откуда взят фрагмент знания. Сейчас источники видят только администраторы (R-0045). Показывать текст фрагментов можно, только если лицензия это разрешает, поэтому в граф берём только такие источники.

Что делаем:
- В разбор попадают только источники с разрешённой лицензией или без необходимости в ней: общественное достояние, CC0, CC BY, CC BY-SA, открытые учебники под такими лицензиями, документация под MIT, Apache, BSD, и источники, на которые у нас есть права (загружены правообладателем с согласием). Источник без лицензии или с неизвестной лицензией не разбирается.
- Лицензия и её проверка хранятся у источника; белый список лицензий — в настройках.
- Учащийся в теории узла видит у каждого утверждения ссылку: название, автор, лицензия, место (страница, раздел) и переход к оригиналу по адресу с якорем. Текст фрагмента показывается учащемуся с атрибуцией, которую требует лицензия.
- Администратор и специалист по-прежнему видят всё, включая журнал проверки.
- R-0045 («источники видят только администраторы») меняется: нужно новое требование, которое его заменяет.

Открытый вопрос: брать ли CC BY-NC (некоммерческие) — зависит от бизнес-модели (P-0014).

Готово, когда: источник без разрешённой лицензии не попадает в разбор; у учащегося у каждого утверждения теории есть рабочая ссылка на место в оригинале.
