# Требование: инструмент загрузки проверенных учебников в граф

Администратор или специалист загружает PDF базового учебника (математика, изучение языков, программирование и т. д.) в канон графа.

1. Форма загрузки: файл, предмет, уровень, издание, источник, лицензия (если известна).
2. Оглавление и заголовки глав дают **скелет**: главы → темы; модель нормализует их в понятия, а не придумывает программу.
3. Для каждого понятия объяснение, примеры и частые ошибки берутся из конкретных фрагментов со ссылкой на страницу.
4. Результат — черновик (статус «черновик от LLM», уверенность); в канон попадает после подтверждения специалиста.
5. Связи берутся из порядка изложения в книге и из оценки модели по паре понятий.
6. Прогресс разбора виден (глав обработано, понятий найдено, противоречий с существующим графом); разбор идёт в фоне.

Это ручной вариант того же конвейера, что и автоматический поиск источников: файл приходит от человека, дальше те же разбор, слияние и черновик.

## Критерии готовности

- Загрузка PDF с текстовым слоем выдаёт понятия с номерами страниц.
- Повторная загрузка того же файла не создаёт дублей.
- Скан без текстового слоя даёт понятную ошибку.
- Источник виден только администраторам.
