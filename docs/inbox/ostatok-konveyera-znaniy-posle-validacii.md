# Остаток конвейера знаний после валидации

Задачи T-0155…T-0174 закрыты по пройденным автоматическим проверкам, но в их журналах осталось недоделанное. Чтобы оно не потерялось вместе с закрытием, собрано здесь.

Что осталось сделать:

- Очередь специалиста (review.py), счётчики областей в обзоре и prior_report по-прежнему считают понятия по «домашней» области, а не через принадлежность областям.
- Карточки повторения строятся из краткого описания узла, а не из готового банка карточек.
- Показ источников утверждения в плашке узла на схеме (сейчас только под теорией шага).
- В пуле проблем нет отмены решения; в клиенте нет кнопки отзыва источника.
- Нет метрики «доля нового» у источника и метрики противоречий в виде отдельного показателя для администратора (карантин по доле спорных утверждений есть).
- Уже сохранённые на устройстве курс и граф остаются на прежнем языке до обновления после смены языка изучения.
- Прежние HTTPException по всему серверу отдают русский текст без кода: перевести на ошибки с кодом по мере касания модулей.
- Живой прогон учебников (T-0151), живая проверка 20 утверждений (V-0130), поиск источников на двух языках на одной области (V-0139) — ждут человека.

Что считается сделанным: каждый пункт либо реализован и проверен, либо снят решением человека.

Чего не делаем: не переписываем закрытые задачи, остаток заводится новыми.
