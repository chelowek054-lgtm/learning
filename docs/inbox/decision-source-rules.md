# Решение: правила использования источников (предложение, владелец принял риск)

Владелец продукта решил: информация берётся из доступных источников, «докуда дотянемся». Рекомендации, чтобы риск оставался управляемым:

- По умолчанию сначала разрешённые открытые источники (OpenStax, LibreTexts, Wikibooks, Project Gutenberg, arXiv, официальная документация), остальное — только после этого и с пометкой.
- Тексты источников хранятся у нас только как материал для разбора и не показываются учащимся; в теорию узла идёт собственное изложение модели с проверкой по источнику.
- Для каждого источника хранится происхождение (адрес, дата, лицензия, если известна), чтобы его можно было отозвать.
- Любой источник можно удалить вместе со всеми утверждениями, выведенными только из него.
- Автоматическое скачивание ограничено белым списком доменов и лимитом на один запрос; расширение списка — решение администратора.

## Не выяснено

- Что делать с жалобой правообладателя: процедура отзыва и сроки.
