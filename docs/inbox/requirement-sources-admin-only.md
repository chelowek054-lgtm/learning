# Требование: источники видят только администраторы

Ссылка на источник, просмотр файла из хранилища и фрагмент, из которого выведено утверждение, доступны **только администраторам и специалистам**. Учащийся видит изложение без цитат источника и без ссылки на исходный файл.

- Доступ к файлам в объектном хранилище только по подписанным временным ссылкам, которые выдаёт проверенный запрос администратора; публичных адресов у бакета нет.
- Учащийся видит статус понятия («черновик» или «проверено»), но не то, из какой книги оно взято.
- Правило проверяется тестом: обычный пользователь не получает ссылки и фрагменты ни в одном ответе API.
