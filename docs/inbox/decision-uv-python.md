# Решение: uv для Python-окружения backend

Когда принято: 2026-07-04. Статус: принято.

## Зачем решали

На Ф0 оставался открытым вопрос: poetry или uv.

## Что решили

Backend — проект на **uv** (Python 3.12), `uv.lock` лежит в репозитории. В Docker-образ `uv` ставится **из PyPI**, а не копируется из `ghcr.io/astral-sh/uv`: демон Docker в среде разработки не достаёт `ghcr.io` (TLS handshake timeout).

## Отвергнуто и почему

- **poetry**: за — Привычно; против — Медленнее, отдельный формат lock.
- **uv**: за — Быстро, один инструмент; против — Моложе.

## Последствия

Установку uv в образе нельзя «оптимизировать» обратно на ghcr.io (HANDOFF §3).
