Обновить карту пользовательских путей: список экранов для вкладки «Дизайн»

Зачем: вкладка «Дизайн», раздел «Экраны», берёт список экранов из подтверждённой карты пользовательских путей (блок `docdd-userflow`). Сейчас в картах проекта девять экранов старых маршрутов (`/`, `/course`, `/graph`, `/profile`, `/activities`, `/placement`, `/progress`, `/review`, `/materials`). Приложение с тех пор изменилось: вкладки «Путь» и «Прогресс» вместо «Курс» и «Граф», появились «Моя библиотека», «Куратор», «Состав навыка», «Источники». По устаревшему списку консоль не найдёт снимки и не проверит нужные экраны.

Что считается сделанным: новая карта (не правка старых) задаёт актуальные экраны и снимает `/course` и `/graph`; названия у экранов человеческие; для каждого экрана ниже в `design/screens/<экран>/<ширина>-<тема>.png` лежат снимки на 375, 768 и 1280 в светлой и тёмной темах.

Экраны клиента сейчас (файл → маршрут → название):
- `learningFront/src/app/(tabs)/index.tsx` → `/` → Сегодня
- `learningFront/src/app/(tabs)/path.tsx` → `/path` → Путь
- `learningFront/src/app/(tabs)/progress.tsx` → `/progress` → Прогресс
- `learningFront/src/app/(tabs)/profile.tsx` → `/profile` → Профиль
- `learningFront/src/app/library.tsx` → `/library` → Моя библиотека
- `learningFront/src/app/skill-profile.tsx` → `/skill-profile` → Состав навыка
- `learningFront/src/app/placement.tsx` → `/placement` → Определить, что я знаю
- `learningFront/src/app/review.tsx` → `/review` → Повторение
- `learningFront/src/app/materials.tsx` → `/materials` → Мои материалы
- `learningFront/src/app/sources.tsx` → `/sources` → Источники знаний (куратор)
- `learningFront/src/app/curator.tsx` → `/curator` → Куратор (только администратор)
- `learningFront/src/app/activities.tsx` → `/activities` → Служебный список активностей (только администратор)

Состояния, которые стоит снимать отдельными снимками, потому что вид у них разный (имя экрана плюс состояние): «Сегодня» — нет предмета, карта собирается, сбой сборки, контур готов, нужно определить уровень, есть шаг, повторение, цель достигнута, пауза; «Путь» — шаги, дерево, карта (схема графа), аккордеон «Весь путь»; «Состав навыка» — контур, сборка, готово; «Профиль» — учащийся и администратор.

Переходы между экранами (что вызывает что): Сегодня → шаг курса / Повторение / Определить, что я знаю / Состав навыка / Моя библиотека; Путь → карточка понятия → шаг курса; Профиль → Моя библиотека, Куратор, Мои материалы; Куратор → Источники. Свидетельства (файл и строка) берёт приложение при разборе, я их не выдумываю.

Чего не делаем: не снимаем экраны вручную в этой заметке; снимки кладёт сборка или человек. Макеты Claude Design (лист «Реестр экранов» и «Ключевые экраны») лежат в артефакте https://claude.ai/artifact/Cu9nQgUixTpE2KsmvuNTLd, их PNG можно экспортировать в `design/mockups/<экран>.png` как эталон для прохода Pixel-Perfect.
