Отсев неликвидных источников: воронка от дешёвых проверок к дорогим

Зачем: на вход приходит литература разного качества: копии, сканы с плохим распознаванием, рекламные статьи, тексты не по теме, ошибочные. Сейчас фильтр — только белый список доменов. Каждый лишний источник стоит запросов к модели при извлечении и сверке.

Что делаем — воронка, дешёвые проверки первыми, модель последней:
1. До скачивания: лицензия из разрешённого списка, домен из белого списка, тип источника (учебник, конспект лекций, статья, документация, энциклопедия), язык, лимиты размера.
2. После скачивания, без модели: дубль по хешу и почти-дубль по тексту (зеркала и копии), качество извлечённого текста (доля мусорных символов, качество распознавания, минимальная длина), доля служебного текста и рекламы, наличие структуры (оглавление, заголовки).
3. По теме, без модели: близость вектора оглавления и заголовков к целевой области; ниже порога — отказ.
4. Одна проба моделью на документ: 5–10 случайных фрагментов — учебный ли это текст, уровень, явные ошибки. Итог — уровень доверия A, B или C либо отказ, с причинами.
5. После извлечения, по метрикам: доля утверждений, отброшенных из-за ненайденной цитаты; доля утверждений, противоречащих принятым; доля нового (источник ничего не добавил — остаётся только как подтверждающий). Плохие метрики — понижение уровня или карантин.

Правила доверия: источник уровня C никогда не бывает единственной опорой утверждения в теории; источник в карантине не участвует в сборке узлов, пока его не посмотрит администратор.

Готово, когда: у каждого принятого источника есть уровень доверия и причины; отказ на каждом шаге воронки виден администратору с причиной; запросы к модели тратятся только на источники, прошедшие проверки 1–3.
