Утверждение — единица знания графа, понятие — набор утверждений

Зачем: сейчас единица слияния и проверки — целое понятие (название + короткое описание). Цитата сверяется с фрагментом, но это доказывает только, что фраза есть в книге. Расхождения между источниками ловятся лишь на уровне «понятие против понятия», теория строится по требованию по трём фрагментам и не ссылается на источник. Нужна единица мельче: атомарное утверждение со ссылкой на точное место в источнике.

Что делаем:
- Утверждение (claim): понятие, вид (определение, свойство, формула, условие, пример, типичная ошибка), текст, вектор, статус (подтверждено несколькими источниками / один источник / спорно / заменено), область применимости (например «с версии 3.12»), дата актуальности.
- Ссылка утверждения на источник: фрагмент, дословная цитата, смещения начала и конца в тексте фрагмента, отметка «цитата найдена». Цитата сверяется без модели, как сейчас.
- Фрагмент получает точный якорь: страница, заголовок, смещения в тексте и адрес с якорем на страницу или текст, чтобы можно было перейти к месту.
- Извлечение из источника (одно обращение к модели на окно фрагментов, как сейчас) возвращает понятия и их утверждения, а не только summary.
- Понятие хранит набор утверждений; теория, задания и карточки собираются из утверждений (отдельная заметка про сборку узла).

Чего не делаем: не выдумываем утверждения без цитаты; утверждение без найденной цитаты отбрасывается.

Нынешний граф — тестовые данные: его можно удалить и пересобрать по новой схеме, миграция старых понятий не нужна.

Готово, когда: у каждого опубликованного понятия есть список утверждений, у каждого утверждения — хотя бы одна ссылка на место в источнике с проверенной цитатой.
