# Проверки: Импорт PDF/Markdown как источник персонального графа

## Зачем

Показать фактом, что требование R-0011 выполнено, а не только объявлено. Проверяет требование R-0011; задачи, которые оно порождает, — T-0014, T-0015, T-0016. Каждая проверка ниже — отдельная запись-проверка; по ней задача сможет закрыться только с пройденным прогоном.

## Проверка 1: Извлечение текста и лимиты

- Вид: unit
- Чем запускается: pytest
- Команда: `будет: cd learningBack && uv run pytest tests/test_material_import.py -q`
- Что доказывает: PDF и Markdown до 20 МБ разбиваются на фрагменты, больший файл отклоняется с причиной.
- Считается пройденной, когда: тест написан вместе с T-0014
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0011; задачи T-0014, T-0015, T-0016
