# Решение: Offline-first: локальная БД — источник правды для действий; LWW; один активный девайс

Когда принято: 2026-07-04. Статус: принято.

## Зачем решали

Люди учатся в дороге, где сети нет. AI-оценка требует сети и стоит денег. Отсутствие сети не должно мешать *делать* — оно должно только откладывать *оценку*.

## Что решили

- Локальная SQLite — источник правды для ответов, повторений и очереди задач; Postgres — для AI-контента и графа.
- Каждый тип Activity несёт флаг `connectivity`; отдельной «оффлайн-версии» нет.
- AI-работа — отложенная задача (`job`), созданная офлайн с клиентским UUID и исполняемая при сети; повторная отправка идемпотентна.
- Конфликты — last-write-wins на уровне записи; `response` иммутабелен, кроме дописывания `grade`. Один активный девайс на пользователя.

## Отвергнуто и почему

- **Online-only**: за — Проще; против — Бесполезно без сети.
- **CRDT**: за — Корректная работа с нескольких устройств; против — Сложность, несоразмерная MVP.

## Последствия

При работе с двух устройств возможен откат интервала FSRS. До Ф6 это принято (P6-SYNC-01). Шаги курса требуют сети для проверки ответа: теорию можно читать офлайн, а ответ оценивает сервер.
