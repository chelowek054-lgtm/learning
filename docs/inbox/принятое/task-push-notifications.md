# Задача: доставка уведомлений вне приложения (push)

Уведомления о курсе лежат в базе и показываются только при открытии курса. Критерий R-0044: «доходят и без открытого приложения».

- Канал push для мобильного клиента: регистрация токена устройства, отправка при создании уведомления, отписка при выходе и удалении аккаунта.
- Человек может отключить push в настройках; без согласия ничего не отправляется.
- Текст push не содержит содержания источников и личных данных, только «Курс готов» / «Курс дополнен» и область.
- Доставка не блокирует создание уведомления: сбой канала не ломает сборку курса и разбор документа.

## Критерии готовности

- Токен устройства хранится и удаляется вместе с аккаунтом.
- Уведомление «курс готов» приходит на устройство при закрытом приложении.
- Отключённый push не отправляется; сбой отправки логируется и повторяется ограниченное число раз.

## Не выяснено

- Выбор провайдера push (Expo Push или напрямую FCM/APNs); зависит от сборки через EAS (T-0034) и проверки на устройстве.
