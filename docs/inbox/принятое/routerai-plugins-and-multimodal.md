# RouterAI: плагины и мультимодальные входы (справка провайдера)

Источник: документация RouterAI (получена от человека 2026-10-07).

## Плагины

Передаются массивом `plugins` в теле запроса; заранее настраивать не нужно.

| Плагин | ID | Что делает |
|---|---|---|
| Веб-поиск | `web` | Дополняет ответы свежими результатами из интернета |
| Работа с PDF | `file-parser` | Разбор и извлечение содержимого загруженных PDF |

Быстрое включение веб-поиска: суффикс `:online` к модели (`openai/gpt-4o:online`) — то же, что `plugins:[{"id":"web"}]`.

## Мультимодальность

Все входы идут на `/api/v1/chat/completions`, типы контента внутри `messages[].content`:
изображения — `image_url`; PDF — `file`; аудио — `input_audio`; видео — `video_url`. Можно смешивать модальности в
одном запросе; число файлов зависит от провайдера и модели. RouterAI сам отфильтровывает модели без нужной
модальности (vision, работа с файлами, аудио, видео).

Форматы подачи: URL (рекомендуется для публичного контента: изображения, PDF; аудио по URL не поддерживается;
видео — зависит от провайдера, например YouTube для Gemini на AI Studio) и base64 (для локальных файлов:
`data:image/jpeg;base64,...`, `data:application/pdf;base64,...`, `data:video/mp4;base64,...`; аудио — сырая
строка base64 с указанием формата).

Отдельные эндпоинты: распознавание речи `/api/v1/audio/transcriptions` (аудио base64 → JSON с текстом и
статистикой использования), синтез речи `/api/v1/audio/speech` (совместим с OpenAI Audio Speech; текст → байты
`mp3` или `pcm`), генерация изображений (модели с выводом изображений). Подробности по ним в исходной документации
не приведены.
