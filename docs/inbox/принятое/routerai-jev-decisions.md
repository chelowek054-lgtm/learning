# RouterAI: Jev — модель решений вместо текста (справка провайдера)

Источник: документация RouterAI, раздел decisions (получена от человека 2026-10-07). Зафиксировано как есть,
анализ применения — отдельным шагом.

## Что это

Jev (TypeSafe) — не чат-модель: текст не генерирует. Получает `state` (текст/данные) и `questions` с заранее
известными вариантами ответа, возвращает готовые значения: вероятность «да», выбранный вариант, оценку по шкале.
Парсить JSON из текста не нужно.

- Эндпоинт: `POST https://routerai.ru/api/v1/decisions`. Ключ — обычный ключ RouterAI (отдельный аккаунт TypeSafe не нужен).
- Модель: алиас `~typesafe/jev-latest` (всегда актуальная версия) или закреплённая, например `typesafe/jev-1.13`.
  В ответе поле `model` — датированный снимок (например `typesafe/jev-1.13-20260917`).
- Тело запроса: только `model`, `state`, `questions`. Параметры `temperature`, `response_format`, `reasoning`
  не работают; на chat/completions и другие эндпоинты Jev не обслуживается.
- Вопросы и критерии можно писать по-русски.

## Свойства

- Быстро: меньше секунды, сколько бы вопросов ни было (обрабатываются параллельно, друг друга не видят).
- Дёшево: тарифицируются только входные токены (`state` и вопросы); выходные бесплатны. Около 280 служебных
  токенов на запрос, поэтому десять вопросов одним запросом заметно дешевле десяти запросов по одному.
  Русский текст дороже английского по токенам. Цена — на странице модели.
- Предсказуемо: ответ всегда из предложенных вариантов.
- Честно про сомнения: приходят вероятности.
- Контекст: 32 000 токенов на `state` и самый длинный вопрос, 64 000 на `state` и все вопросы вместе.
- Объяснений и рассуждений не возвращает. Причину можно получить, задав `choice` с вариантами-причинами.

## Три типа вопросов

| Тип | Вопрос | Возвращает |
|---|---|---|
| `noul` | да или нет | `noul` — вероятность «да», 0..1 (отдельного `confidence` нет: около 0,5 — «не знаю») |
| `choice` | какой вариант из списка | `choice` — победитель, `probabilities` по вариантам, `confidence` |
| `score` | где на шкале | `score` — положение на шкале, `probabilities` по уровням, `confidence`, `legend` |

Форма вопроса: `{"type": ..., "instructions": "...", "criteria": ...}`; для `choice` criteria — объект
«вариант: описание», для `score` — список уровней по порядку (индекс 0 — первый уровень).
Типы в одном запросе можно смешивать. Имя вопроса придумывает вызывающий, под ним приходит ответ.

## Когда Jev, а когда чат-модель

Jev: определить тему/отдел/намерение/язык/тип документа; проверить наличие признака (срочность, жалоба,
персональные данные, попытка взлома промпта); оценить по шкале; промодерировать список одним запросом;
выбрать, какому обработчику отдать запрос. Правило: вопросы, на которые знающий человек ответит за пару секунд,
взглянув на текст. Многошаговый анализ — разбить на простые вопросы и собрать в коде.
Чат-модель: написать, пересказать, перевести, сгенерировать код. Подсчёты и многошаговые задачи — код или модель
с рассуждениями.

## Уверенность и пороги

Зоны: высокая — действовать автоматически; средняя — переспросить или пометить; низкая — человеку или более
сильной модели. Пороги зависят от цены ошибки и подбираются на своих примерах с известными ответами. Если пороги
подобраны под версию, закрепить версию (`typesafe/jev-1.13`) и логировать поле `model` из ответа; алиас
`jev-latest` после обновления может изменить поведение.

## Стоимость в ответе

`usage` содержит только токены. Стоимость в рублях — `GET /api/v1/generation?id=<id>` (поле `total_cost`),
`id` берётся из заголовка `X-Generation-Id` или поля `id` ответа; также история запросов в кабинете.

## SDK

Официальные `@typesafe-ai/sdk` (JS/TS) и `typesafe-sdk` (Python) работают с RouterAI: `base_url=https://routerai.ru/api`,
ключ RouterAI (или переменные `TYPESAFE_BASE_URL`, `TYPESAFE_API_KEY`). Имена моделей: `jev-latest` →
`~typesafe/jev-latest`, `jev-1.13` → `typesafe/jev-1.13`. `client.models.list()` не работает (формат каталога другой);
стоимость SDK не показывает.

## Пример (суть)

`state` — текст обращения; вопросы `is_urgent` (noul), `department` (choice: billing/technical/sales),
`frustration` (score по трём уровням). Ответ: `is_urgent.noul=0.98`, `department.choice="billing"` с
`confidence 0.61` (technical 0.26 — вариантов два), `frustration.score=0.88`; `usage` 633 входных токена на запрос.
