# Навигация приложения: куда что переезжает

Часть сквозного пути (`user-flow-journey`). Решаем, где человек ищет вещи, не глядя в устройство кода.

## Вкладки

Остаётся четыре, но каждая отвечает на один вопрос человека.

| Вкладка | Вопрос | Что внутри |
|---|---|---|
| **Сегодня** | Что мне делать сейчас? | Одно главное действие по состоянию предмета; ход сборки; спокойная строка про остальное |
| **Путь** | Куда я иду и что уже пройдено? | Переключатель «Шаги / Карта»: шаги курса списком и карта знаний по этапам с уровнями; «Состав навыка»; «Откуда знания» (материалы и источники) |
| **Прогресс** | Как у меня идёт? | Освоено и осталось, удержание, рост по критериям, граница относительно цели |
| **Профиль** | Мои настройки и данные | Аккаунт, способ запоминания, оформление, синхронизация, уведомления, мои данные и удаление, выход |

«Курс» и «Граф» сливаются во вкладку «Путь»: это два взгляда на одно и то же, и человек их сейчас не связывает.
«Прогресс» поднимается из настроек во вкладку.

## Предмет в шапке

Шапка «Сегодня», «Путь» и «Прогресс» несёт название предмета и позволяет переключить его или завести новый.
Переключение не сбрасывает онбординг и не стирает данные другого предмета.

## Куда уходит всё из нынешнего «Профиля»

| Было в профиле | Станет |
|---|---|
| Прогресс | вкладка «Прогресс» |
| Мои материалы | «Путь» → «Откуда знания» |
| Профиль навыка | «Путь» → «Состав навыка» (человеческое название) |
| Источники знаний | раздел куратора (только админу), см. `user-flow-curator` |
| Разработчику | раздел куратора, скрыт от учащегося |
| Способ запоминания, оформление, синхронизация | остаются в «Профиле» |
| Определить уровень | кнопка на «Сегодня» и в «Путь», не отдельный пункт настроек |

## Правила

1. На вкладке не больше одного главного действия.
2. Назад ведёт туда, откуда пришли; из любого экрана «Сегодня» достижимо одним касанием.
3. Экран, который зависит от предмета, без предмета не пустой, а объясняет и ведёт к началу.
4. Уведомления (готова карта, обновилось понятие, пора повторить) открывают тот экран, о котором речь, а не
   «Сегодня».
5. Администратору добавляется пятая точка входа «Куратор», не меняющая вкладки учащегося.
