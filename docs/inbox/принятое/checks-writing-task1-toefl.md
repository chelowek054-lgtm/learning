# Проверки: Письмо: IELTS Task 1 и TOEFL writing

## Зачем

Показать фактом, что требование R-0012 выполнено, а не только объявлено. Проверяет требование R-0012; задачи, которые оно порождает, — T-0017, T-0018. Каждая проверка ниже — отдельная запись-проверка; по ней задача сможет закрыться только с пройденным прогоном.

## Проверка 1: Рубрики Task 1 и TOEFL в реестре

- Вид: unit
- Чем запускается: pytest
- Команда: `будет: cd learningBack && uv run pytest tests/test_writing_rubrics.py -q`
- Что доказывает: Рубрики заведены с версиями, выбор по цели профиля отдаёт нужную.
- Считается пройденной, когда: тест написан вместе с T-0017 и T-0018
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0012; задачи T-0017, T-0018

## Проверка 2: Оценка на реальной модели

- Вид: manual
- Чем запускается: вручную
- Команда: нет, проверка не автоматическая
- Что доказывает: Эссе Task 1 и TOEFL оцениваются по своим рубрикам, разбор содержит критерии и ошибки.
- Считается пройденной, когда: проходится руками с ключом
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0012; задачи T-0017, T-0018
