# Проверки: платформа — граф, способы запоминания, изоляция, данные пользователя

## Зачем

Показать фактом, что платформенные требования R-0028, R-0029, R-0030 и R-0031 выполнены, а не только объявлены; проверить контракт C-0001. Проверка независимости ядра от предметов уже есть и прошла (V-0003), её стоит держать и для требования R-0027. Остальных проверок ещё нет: каждая появится вместе с соответствующей задачей.

## Проверка 1: Граф без предметов

- Вид: integration
- Чем запускается: pytest
- Команда: будет: `cd learningBack && uv run pytest tests/test_graph_subject_agnostic.py -q`
- Что доказывает: один и тот же код графа строит область и ведёт курс для трёх предметов разной природы (технический, языковой, произвольный); в модуле нет проверок по названию предмета.
- Считается пройденной, когда: тест написан вместе с задачей про граф без предметов и проходит.
- Состояние: ещё нет.
- Проверяет: R-0028.
