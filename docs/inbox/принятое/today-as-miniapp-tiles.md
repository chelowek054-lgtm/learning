# «Сегодня» плашками: мини-приложения работы с основными данными и повторением

Со слов человека (2026-10-07): раздел «Сегодня» нужно реализовать плашками в виде мини-приложений работы с
основными данными и повторением материала пользователя.

## Что видно сейчас (свидетельство)

«Сегодня» показывает одну карточку «Следующий шаг» (название понятия, строка «Следующий шаг вашего пути»,
«Пройдено 0 из 181») и строку «Ещё 1 карточек ждут повторения — можно после шага». Остальное пространство
пустое. Код: `pages/home/ui/home-screen.tsx`, логика — `pages/home/model/next-action.ts` (R-0057: одно главное
действие по состоянию предмета).

## Что считается сделанным

1. «Сегодня» — сетка плашек, каждая плашка — мини-приложение со своим коротким видом и входом в полный экран:
   «Следующий шаг», «Повторение» (сколько карточек, сколько просрочено), «Освоено сегодня», «Слабые места»
   (понятия с ошибками), «Продолжить чтение материала», «Проверка уровня», «Цель и срок» и т. д.
2. Плашка получает данные из графа знаний и событий обучения через общий контракт, а не лезет в таблицы
   сама. Плашка работает самостоятельно: открывается, живёт и обновляется независимо от остальных.
3. Главное действие дня остаётся одним и заметным (R-0057): плашка «Следующий шаг» крупнее остальных и всегда
   первая; остальные — вторичны. Состояния предмета (собирается, сбой, цель достигнута) показываются тоже
   плашками.
4. Набор и порядок плашек у человека настраиваемы (скрыть, переставить); для нового человека — разумный набор
   по умолчанию.
5. Офлайн: плашки показывают последнее известное и честно говорят об этом.

## Связь с имеющимися записями

- R-0057 / T-0105 — состояния предмета на «Сегодня»: остаются как логика главной плашки, не отменяются.
- R-0059 / T-0111 — вкладки: «Сегодня» остаётся первой вкладкой, меняется содержимое.
- `miniapp-platform` — рамка мини-приложений: плашки «Сегодня» первые её потребители.
- user-flow-daily-loop, user-flow-screens S-10 — состояния экрана, которые плашки обязаны покрывать.

## Что мешает

Противоречие с принципом «следующий шаг всегда один» (`user-flow-journey`, принцип 6): плашки добавляют
вторичные блоки. Решение: один заметный главный шаг и спокойные вторичные плашки; число видимых плашек без
прокрутки ограничено.
