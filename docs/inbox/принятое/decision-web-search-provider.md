# Решение: провайдер веб-поиска для поиска источников (ждёт вашего выбора)

Поиск источников требует выхода в сеть: список учебников и литературы по теме, которой не хватает в графе.

## Что нужно

- Поиск по запросу «что читать по теме X на уровне Y» с адресами и краткими описаниями.
- Скачивание найденного с учётом белого списка доменов (см. «Решение: правила использования источников»).
- Лимит запросов и стоимости на один запрос человека.

## Варианты

1. **API поиска** (Brave Search API, Tavily, SerpAPI и подобные): предсказуемая цена за запрос, выдача разбирается нашим кодом; провайдер видит текст запроса (тему обучения).
2. **Модель со встроенным поиском** (у части провайдеров LLM): проще в коде, но цена и качество ссылок зависят от провайдера, меньше контроля над выдачей.
3. **Собственный поиск по белому списку** (OpenStax, LibreTexts, Wikibooks, arXiv и др. через их API и каталоги): бесплатно и безопаснее по лицензиям, но покрытие ограничено выбранными сайтами.

## Предложение

Начать с варианта 3 (белый список с каталогами) как основы и добавить вариант 1 для того, чего там нет; вариант 2 не брать, пока нет требования к одному провайдеру.

## Не выяснено

- Бюджет на поиск и скачивание; какой провайдер подходит по условиям данных.
