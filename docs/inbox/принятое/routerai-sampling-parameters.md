# RouterAI: параметры генерации (справка провайдера)

Источник: документация RouterAI (получена от человека 2026-10-07). RouterAI принимает любые параметры из списка,
подставляет значения по умолчанию, а провайдер-специфичные (`safe_prompt` у Mistral, `raw_mode` у Hyperbolic)
передаёт провайдеру как есть.

| Ключ | Тип, диапазон | По умолчанию | Смысл |
|---|---|---|---|
| `temperature` | float 0.0–2.0 | 1.0 | Разнообразие; 0 — один и тот же ответ на один ввод |
| `top_p` | float 0.0–1.0 | 1.0 | Ограничение набором токенов с суммой вероятностей P (динамический top-k) |
| `top_k` | int ≥ 0 | 0 (выкл.) | Выбор из k лучших токенов; 1 — всегда самый вероятный |
| `frequency_penalty` | float −2.0…2.0 | 0.0 | Штраф, растущий с числом вхождений токена |
| `presence_penalty` | float −2.0…2.0 | 0.0 | Штраф за сам факт повторения, не растёт с числом вхождений |
| `repetition_penalty` | float 0.0–2.0 | 1.0 | Борьба с повтором токенов входа; слишком высокий снижает связность |
| `min_p` | float 0.0–1.0 | 0.0 | Минимальная вероятность относительно самого вероятного токена |
| `top_a` | float 0.0–1.0 | 0.0 | Динамический top-p по вероятности лучшего токена |
| `seed` | int | — | Детерминированное сэмплирование (не гарантируется у всех моделей) |
| `max_tokens` / `max_completion_tokens` | int ≥ 1 | — | Верхний предел выходных токенов (≤ контекст минус промпт) |
| `logit_bias` | map токен→−100…100 | — | Смещение логитов; ±100 запрещает/форсирует токен |
| `logprobs` / `top_logprobs` | bool / int 0–20 | — | Логарифмические вероятности выходных токенов |
| `response_format` | map | — | `{"type":"json_object"}` — режим JSON (в промпте тоже попросить JSON) |
| `structured_outputs` | bool | — | Может ли модель отдавать структурированный вывод по `json_schema` |
| `stop` | array | — | Немедленная остановка на любом из токенов |
| `tools` / `tool_choice` | array / string или object | — | Вызов инструментов (формат OpenAI; `none`/`auto`/`required`/конкретная функция) |
| `parallel_tool_calls` | bool | true | Параллельный вызов функций |
| `verbosity` | enum low/medium/high/xhigh/max | medium | Многословность ответа; для Anthropic соответствует `output_config.effort` (`xhigh` — Opus 4.7+, `max` — Opus 4.6+) |
