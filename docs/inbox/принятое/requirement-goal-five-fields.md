# Требование: из запроса человека извлекаются пять полей цели

Человек пишет свободно: «Я хочу изучить X до такого-то уровня, потому что…». Из текста система выделяет пять полей и подтверждает их с человеком (диалог цели уже есть: уточняющие вопросы, пересказ, подтверждение; граф до подтверждения не строится).

1. **Область**, в которой человек хочет разобраться.
2. **Целевой уровень** (понять, применять, создавать; для языков — уровень по шкале экзамена или CEFR).
3. **Зачем**: цель применения (экзамен, работа, проект, интерес) — от неё зависит, какие темы важны.
4. **Что уже знает** — со слов человека; проверяется тестом (см. «Требование: проверка предварительных знаний»).
5. **Ограничения**: срок, время в неделю, предпочитаемый формат.

Пять полей достаточно: больше уточнений — человек бросает диалог. Пропущенное поле не блокирует построение, а берётся по умолчанию с пометкой «предположили».

## Критерии готовности

- Любой свободный запрос даёт значения (или явное «не указано») для всех пяти полей.
- Подтверждённая цель хранит поля структурно и передаёт их построению графа и курса.
- Без сети остаётся прямая форма с теми же пятью полями.

## Не выяснено

- Как хранить «зачем»: свободным текстом или набором типовых целей.
