# Проверки: Граф знаний для языкового домена

## Зачем

Показать фактом, что требование R-0013 выполнено, а не только объявлено. Проверяет требование R-0013; задачи, которые оно порождает, — T-0019, T-0020. Каждая проверка ниже — отдельная запись-проверка; по ней задача сможет закрыться только с пройденным прогоном.

## Проверка 1: Решение по языковому графу принято

- Вид: review
- Чем запускается: вручную
- Команда: нет, проверка не автоматическая
- Что доказывает: ADR принят человеком и отражён в архитектурном описании модели знаний.
- Считается пройденной, когда: человек подтвердил запись решения
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0013; задачи T-0019, T-0020

## Проверка 2: Курс по предмету «Английский B2»

- Вид: manual
- Чем запускается: вручную
- Команда: нет, проверка не автоматическая
- Что доказывает: Предмет получает граф с ядром и курс, в который встроены дриллы рецепции.
- Считается пройденной, когда: проходится руками после T-0020
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0013; задачи T-0019, T-0020

## Не выяснено

- Не выяснено: как ложатся канон, ядро и курс на язык, который менее иерархичен, чем ML.
