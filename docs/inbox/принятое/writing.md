# Письмо IELTS Task 2

## Зачем

Проверить главную гипотезу продукта (scope): AI-оценка эссе по официальным критериям с разбором ошибок, которые затем тренируются повторением.

## Состояние

реализовано (live web + backend live; на устройстве не проверено — NFR-18)

## Как должно вести себя

1. Учащийся открывает Activity `ielts_writing_task2`: видит задание (`payload.prompt`) и поле ввода со счётчиком слов.
2. **Отправка работает без сети.** Ответ пишется в `response`, ставится job `grade_writing` с `rubricId='ielts_writing_task2'`.
3. **Черновой сигнал** сразу, офлайн: локальный грейдер оценивает объём (порог 250 слов), структуру абзацев и покрытие AWL. Сигнал помечен `gradedOfflineFallback: true` и не выдаётся за оценку.
4. **При сети** запускается sync; сервер оценивает эссе по рубрике. Разбор содержит 4 критерия с баллами 0–9 и комментариями, `overall` (среднее, округлённое до 0.5), ошибки с исправлением и объяснением, образец переписанных предложений.
5. Ошибки становятся карточками повторения (SPEC-05).

## Что система обязана обеспечить

- Учащийся пишет эссе IELTS Task 2 по заданию, видит счётчик слов. Признак: Эссе сохраняется офлайн. (Сейчас: реализовано; прежний номер — FR-WRT-01.)
- Сразу после отправки учащийся видит черновой офлайн-сигнал: объём, абзацы, покрытие AWL. Признак: Сигнал появляется без сети и помечен как черновой. (Сейчас: реализовано; прежний номер — FR-WRT-02.)
- При сети эссе оценивается по 4 критериям IELTS с ошибками и образцом. Признак: Разбор: 4 критерия с баллами, `overall`, ошибки с исправлением, образец. (Сейчас: реализовано; прежний номер — FR-WRT-03.)
