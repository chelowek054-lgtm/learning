# Требование: роль «специалист» и очередь проверки

Подтверждать черновики могут администраторы и специалисты по области.

- Роль специалиста назначает администратор на конкретные области (не на всю систему).
- Очередь проверки: новые и изменённые понятия по области, с источником, оценкой уверенности модели и найденными противоречиями; действия — подтвердить, исправить, отклонить с причиной.
- Решения специалиста попадают в журнал (кто, когда, что изменил).
- Сейчас есть только флаг суперпользователя; нужны права по областям.

## Не выяснено

- Как проверяется квалификация специалиста и можно ли доверять нескольким независимым подтверждениям вместо одного.
