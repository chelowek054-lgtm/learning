# Выполнено: задания из теории узла и оценка ответа

## Зачем

Оформить задачей работу по требованию R-0005, которая уже сделана и проверена. Это не новая разработка: описано то, что есть в коде, со ссылками на пройденную проверку.

## Что считается сделанным

- Задания генерируются из теории узла по ступени понимания и форме (проверка, практика, зонд); пара ступень/форма вне допустимых отвергается, узел без пригодной теории отсекается до вызова модели.
- Задания кэшируются по узлу, его версии, ступени и форме; правка теории поднимает версию и обесценивает кэш, строки прошлых версий удаляются.
- Закрытый вопрос оценивается локально по отмеченному варианту, без модели; открытый оценивается моделью по эталону из узла с результатом от нуля до единицы, а без ключа — по совпадению ключевых слов.
- Дистракторы строятся из заблуждений узла, практика — из его примеров.
