# Задача: автоматический поиск источников по областям «нет в графе»

Сейчас отчёт по предварительным знаниям (T-0075) только перечисляет области, которых в графе нет вообще, а источники по ним администратор ищет вручную.

- После теста или отчёта по каждой области «нет в графе» администратору показывается готовый запрос на поиск источников (название области и цель), а не пустое поле.
- Один шаг «найти и поставить в разбор» для выбранных областей: поиск по белому списку (T-0082), скачивание, постановка в очередь разбора; лимиты и белый список те же.
- Человеку (не администратору) источники по-прежнему не показываются; ему видно только, что область пополняется.
- Поиск не запускается дважды для одной области, пока предыдущий не закончился.

## Критерии готовности

- Из отчёта «нет в графе» администратор одним действием запускает поиск по области и видит ход разбора.
- Повторный запуск по той же области в процессе отклоняется с понятной причиной.
- Для не администратора ничего из источников не раскрывается.

## Не выяснено

- Запускать ли поиск без подтверждения администратора или только по его кнопке (пока предлагается по кнопке).
