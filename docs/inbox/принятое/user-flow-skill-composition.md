# «Состав навыка»: показать человеку, из чего состоит то, что он хочет выучить, до долгой сборки

Новая возможность — по правилам процесса сперва в функциональную карту, потом требование, проверка, задача.

## Зачем

Идея продукта: по навыку составить полное описание того, что человеку точно нужно знать, разложить по
областям и этапам и только потом строить граф. Сейчас сборка делает всё одним заходом и показывает
результат через 8–10 минут. Человек не может сказать «эту область я знаю» до того, как модель потратила
на неё время, и не видит, что именно его ждёт.

## Как должно быть

1. После подтверждения цели идёт **быстрый контур**: области (цель и базовые основы под ней) и этапы
   каждой. Это один запрос, около минуты.
2. Человек видит **состав навыка**: «6 областей, 9 этапов», у каждой области — зачем она нужна и сколько
   примерно понятий в ней будет.
3. Может: убрать область, отметить **«уже владею»**, добавить свою, поменять порядок этапов.
4. Может пройти **короткий входной тест по областям** (5–8 вопросов) — результат расставляет отметки
   «хватает / мало / нет» для каждой области. Тест можно пропустить.
5. После «Собрать карту» наполнение понятиями идёт в фоне, **по областям параллельно**, и ход виден
   по областям. Области с отметкой «уже владею» наполняются коротко (опорные понятия) или пропускаются.
6. Готовность области сообщается сразу: человек может начать с первой готовой, не дожидаясь остальных.

## Что уже есть в коде (на чём строится)

- Профиль навыка с областями, этапами, уровнями и «необязательным»: `learningBack/modules/knowledge/skill_profile.py`.
- Правка профиля человеком и подтверждение: `profile_store.py`, `profile_api.py`.
- Тест по базовым областям и отчёт «хватает / мало / нет»: `chain_placement.py`, `prior_report.py`; полнота графа против профиля — `profile_coverage.py`.
- Фоновая сборка с видимым статусом: `profile_store.py` (`request(with_graph=True)`, `dispatch`).

## Чего нет

- Отдельного шага «контур, потом подтверждение, потом наполнение»: сейчас оба идут подряд в одной задаче.
- Хода по областям (есть только общий статус «строится»).
- Отметки «уже владею» в профиле и пропуска наполнения по ней.
- Готовности по областям (карта открывается только целиком).
- Параллели по всем областям (сейчас 4).

## Что считается сделанным

- Контур приходит быстро, человек правит его до того, как идёт наполнение.
- Отметка «уже владею» сокращает объём наполнения этой области.
- На экране сборки по каждой области видно: ждёт, в работе, готово.
- Первая готовая область открывается для работы, остальные дособираются.

## Чего не делаем

- Не заставляем проходить тест: он необязательный.
- Не выдаём сгенерированное моделью за проверенное: область и понятия помечены, пока куратор не проверил.
