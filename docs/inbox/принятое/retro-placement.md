# Выполнено: адаптивный плейсмент по графу

## Зачем

Оформить задачей работу по требованию R-0015, которая уже сделана и проверена. Это не новая разработка: описано то, что есть в коде, со ссылками на проверки.

## Что считается сделанным

- Плейсмент начинается с выбора учащимся целевого уровня; на экране уровни названы по-человечески.
- Освоенность узла — бета-модель с приором из освоенности предпосылок, обновляется по ответу, уверенность считается по объёму свидетельств. Решение — A-0010.
- Зонд подбирается на границе знаний с учётом неопределённости и фундаментальности узла; узлы с неосвоенными предпосылками не зондируются.
- Плейсмент останавливается с кодом причины (граф пуст, нет теории, неопределённости не осталось) и отдаёт карту: известно, на границе, изучается, закрыто предпосылками.

Сервер: `modules/knowledge/mastery.py`, `placement.py`, `answer.py`, эндпоинты плейсмента. Клиент: экран плейсмента. Слито в `main` в фазе модели знаний.
