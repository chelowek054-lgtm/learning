# Путь куратора (администратора): отдельно от учёбы

Часть сквозного пути (`user-flow-journey`). Сейчас у администратора те же вкладки, но другое содержимое
(`pages/graph/ui/graph-screen.tsx` подставляет `GraphCuration` вместо карты для чтения), а «Источники знаний»
и «Разработчику» лежат в «Профиле» вперемешку с настройками.

## Принцип

Куратор тоже может учиться, поэтому его учебные вкладки такие же, как у всех. Курирование — отдельный
раздел «Куратор» (вход из «Профиля», виден только администратору).

## Раздел «Куратор»

| Раздел | Вопрос куратора | Содержимое |
|---|---|---|
| Очередь проверки | Что ждёт моего решения? | Понятия-черновики по областям, с числом новых; «подтвердить», «править», «в ядро» |
| Источники | Откуда взялись знания? | Загрузка, ход разбора, найденные автоматически, ошибки; «чего не хватает в графе» |
| Области | Что есть в реестре? | Области, предпосылки, дубли, склейка близких по векторам |
| Конфликты | Где источники спорят? | Расхождения понятий из разных источников, выбор версии |
| Сборки | Что строится сейчас? | Очередь фоновых задач: профиль, разбор, поиск; повтор и отмена |
| Для разработчика | Что под капотом? | Служебный список активностей, журнал |

## Основные пути

1. **Проверить новую область:** «Очередь проверки» → область → понятия по этапам → подтвердить пачкой, спорные править.
2. **Дополнить область источником:** «Источники» → загрузить → ход разбора → слияние → конфликты → подтвердить.
3. **Закрыть пробел:** «Чего не хватает» → «Найти источники» → ход → проверить найденное.
4. **Разобрать сбой сборки:** «Сборки» → причина → «Повторить».

## Что считается сделанным

- Учащийся нигде не видит инструментов куратора.
- У куратора из любого списка один переход к тому, что требует решения; число ожидающих видно на входе в раздел.
- Любая долгая операция куратора показывает ход и позволяет уйти.
