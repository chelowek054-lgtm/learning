# Визуализация графа в админке

Зачем: администратору/куратору нужно видеть граф знаний не только как таблицу
строк (R-0003 даёт таблицы модулей с фильтрами), а как граф — узлы и связи
между ними, чтобы было видно структуру, а не только списком.

Что считается сделанным: в /admin есть экран, на котором граф (или его часть)
отображается как визуальный граф — узлы и рёбра, а не таблица.

Открытые вопросы (не решено, нужно уточнить с человеком):
- Какой граф показываем: весь канон целиком, граф одной области, или граф
  конкретного человека (персональный слой)?
- Цель — курирование (найти дубли, пропуски, разрывы связей) или просто обзор
  структуры?
- Есть ли пожелания к форме: сеть (force-directed), дерево по областям,
  что-то третье?
- Нужна ли интерактивность (клик по узлу → детали, фильтр по области/этапу)?

Чего не делаем (пока не ясно, вычеркнуть лишнее при разборе):
- не меняем модель данных графа — только способ его посмотреть.
