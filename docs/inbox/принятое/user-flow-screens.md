# Реестр экранов под дизайн

Основа для Claude Design: что нужно нарисовать, в каких состояниях и откуда куда ведёт. Пути и принципы —
в `user-flow-journey`, навигация — в `user-flow-navigation`. Статус: **есть** (экран уже в приложении),
**меняется**, **новый**.

Общие условия для дизайна: телефон в первую очередь (узкая колонка, 16 px по бокам), веб-клиент тем же
кодом; светлая и тёмная темы; русский интерфейс; компоненты из `shared/ui` (Screen, Card, Button, Field,
Label, Muted, Note, Pill, Progress, TopBar, Empty); токены цвета, отступов и кеглей — только из
`shared/config/design.ts`.

Для каждого экрана ниже — состояния, которые нужно нарисовать: пусто / загрузка / в работе / ошибка /
готово / офлайн, где они применимы.

## Что нарисовать в первую очередь

1. **S-07 Карта собирается** и **S-10 Сегодня** во всех состояниях — самая хрупкая часть пути.
2. **S-05 Состав навыка** — новая возможность, нужен дизайн до реализации.
3. **S-20/S-21 Путь** со слитыми «шагами» и «картой».
4. **S-30 Прогресс** как вкладка.
5. Куратор — потом, он работает на том же языке компонентов.

## Что считается сделанным

- Для каждого «нового» и «меняется» экрана есть макет всех перечисленных состояний в светлой и тёмной темах.
- Каждый переход из таблиц имеет стрелку на макете.
- Нет ни одного экрана без «назад» или явного выхода.
