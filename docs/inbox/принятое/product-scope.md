# Границы продукта

## Главная гипотеза

> AI-оценка продукции по рубрикам вместе с error-log, питающим интервальное повторение, и курсом по графу знаний даёт больший прирост, чем изолированные карточки и пассивный контент.

Вторичная гипотеза — про **универсальность**: один доменно-независимый движок Activity обслуживает и язык, и технологии. Новый предмет подключается модулем, ядро при этом не меняется.

## Что входит в продукт

| Возможность | Требования | Этап |
|---|---|---|
| Аккаунт, профиль, выбор предмета и целевого уровня | `FR-AUTH-*`, `FR-UX-01` | MVP |
| Офлайн-first: всё, что делает человек, без сети; sync и очередь AI-задач | `FR-SYNC-*` | MVP |
| Интервальное повторение (FSRS) + error-log | `FR-SRS-*` | MVP |
| Письмо IELTS Task 2 с оценкой по рубрике и черновым офлайн-сигналом | `FR-WRT-01..03` | MVP |
| ML-трек: чтение материала, вспоминание понятия с AI-проверкой | `FR-ML-01..02` | MVP |
| Граф знаний: канон + персональный слой, построение LLM-черновиком, курирование | `FR-KG-*` | Модель знаний |
| Задания из теории узла, плейсмент, персональный курс | `FR-ASM-*`, `FR-PLC-*`, `FR-CRS-*` | Модель знаний |
| Речь (Speaking) с STT и рубрикой; чтение и аудирование на время офлайн | `FR-SPK-*`, `FR-RCP-*` | Речь и рецепция |
| Задачи на код, импорт PDF в граф, граф языкового домена, TOEFL | `FR-ML-03..04`, `FR-WRT-04..05`, `FR-KG-10` | Расширение |
| Доставка кода восстановления, мульти-девайс, публикация в сторах, политика данных | `FR-AUTH-05`, `FR-SYNC-07`, `FR-PRD-*` | Продукт и релиз |

Порядок этапов и их состав — в плане реализации.

## Что не входит

| Не делаем | Почему |
|---|---|
| Социальные функции (ленты, друзья, рейтинги) | Не влияют на главную гипотезу; отвлекают от практики |
| Маркетплейс и авторский контент третьих лиц | Контент порождается из графа и курируется; модерация чужого контента — другой продукт |
| Официальная сертификация баллов | Оценка по рубрике — тренировочный сигнал |
| Полноценный IRT и калибровка заданий | Для плейсмента хватает бета-модели (ADR-0012); IRT — после накопления данных |
| CRDT и одновременная работа на нескольких устройствах | До Фазы 6 один активный девайс и LWW (ADR-0004) |
| Web как целевая платформа | Web-сборка — инструмент разработки; целевые платформы iOS и Android |

## Допущения

- Первый пользователь — сам автор; публичный релиз возможен только после Фазы 6: нужны политика данных, доставка кода восстановления и деплой.
- LLM доступен по OpenAI-совместимому протоколу с tool calling (ADR-0009).
- Язык интерфейса — русский. Язык учебного контента задаётся предметом.
