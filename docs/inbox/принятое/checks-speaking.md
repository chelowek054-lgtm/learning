# Проверки: Устная речь: запись, распознавание, оценка

## Зачем

Показать фактом, что требование R-0023 выполнено, а не только объявлено. Проверяет требование R-0023; задачи, которые оно порождает, — T-0040, T-0041, T-0042, T-0043, T-0044, T-0049. Каждая проверка ниже — отдельная запись-проверка; по ней задача сможет закрыться только с пройденным прогоном.

## Проверка 1: Распознавание на заглушке

- Вид: integration
- Чем запускается: pytest
- Команда: `будет: cd learningBack && uv run pytest tests/test_transcribe_job.py -q`
- Что доказывает: Без ключа STT job transcribe работает на MockSTT; пустая или тихая запись даёт понятную ошибку, а не пустую оценку.
- Считается пройденной, когда: тест написан вместе с T-0041
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0023; задачи T-0040, T-0041, T-0042, T-0043, T-0044, T-0049

## Проверка 2: Оценка по ielts_speaking

- Вид: unit
- Чем запускается: pytest
- Команда: `будет: cd learningBack && uv run pytest tests/test_speaking_rubric.py -q`
- Что доказывает: Четыре критерия и band; у Pronunciation есть пометка об ограничении оценки по тексту; ошибки речи становятся карточками.
- Считается пройденной, когда: тест написан вместе с T-0042 и T-0043
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0023; задачи T-0040, T-0041, T-0042, T-0043, T-0044, T-0049

## Проверка 3: Фоновый воркер для долгих задач

- Вид: integration
- Чем запускается: pytest
- Команда: `будет: cd learningBack && uv run pytest tests/test_worker.py -q`
- Что доказывает: Долгая задача исполняется вне запроса /sync/push и доходит до done.
- Считается пройденной, когда: тест написан вместе с T-0049
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0023; задачи T-0040, T-0041, T-0042, T-0043, T-0044, T-0049

## Проверка 4: Запись и отправка голоса на устройстве

- Вид: manual
- Чем запускается: вручную
- Команда: нет, проверка не автоматическая
- Что доказывает: Запись создаётся и прослушивается офлайн, уходит при сети, после загрузки удаляется с устройства.
- Считается пройденной, когда: проходится руками (задача T-0040)
- Состояние: ещё нет: появится вместе с задачей
- Проверяет: R-0023; задачи T-0040, T-0041, T-0042, T-0043, T-0044, T-0049
