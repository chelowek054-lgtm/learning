# «Весь путь» курса: аккордеон по областям и этапам, а лучше визуальное дерево

Со слов человека (2026-10-07, скриншот вкладки «Курс»): список «Весь путь» из 181 шага одной длинной лентой
неудобен. Нужен как минимум аккордеон с разбивкой по темам и главам по порядку, а лучше визуальное дерево с
удобным перемещением.

## Что видно сейчас (свидетельство)

Вкладка «Курс»: заголовок «Курс · чтобы построю своё», «Пройдено 0 из 181», карточка «Курс готов» с пометкой
о черновиках, карточка «Сейчас» с кнопками «Начать» и «Уже знаю, пропустить», затем «Весь путь» — плоский список
из 181 карточки «номер · название · Черновик · Основа». Области и этапы в нём не видны, хотя в графе они есть
(область, этап, уровень у каждого понятия). Код: `features/course/ui/course-path.tsx`.

## Что считается сделанным

1. **Аккордеон (минимум).** Путь сгруппирован: область → этап → шаги по порядку. Верхний уровень показывает
   название области, число шагов и «пройдено N из M»; открыт только текущий этап, остальные свёрнуты;
   «Сейчас» всегда видно сверху. Состояние свёрнутости запоминается.
2. **Дерево (лучше).** Тот же путь как визуальное дерево: ветви — области, узлы — шаги; пройденное приглушено,
   текущее выделено, закрытое отмечено; перемещение и масштаб пальцем и мышью; нажатие на узел открывает
   карточку шага и «Начать».
3. Переключатель «Список / Дерево» в «Пути»; список остаётся для тех, кому он удобнее и для маленьких экранов.
4. Названия без служебных слов («Черновик» → «не проверено», «Основа» → «обязательное»), как в
   `client-graph-visualization`.
