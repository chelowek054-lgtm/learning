Сборка узла из утверждений и банк заданий: обучение без запросов к модели

Зачем: сейчас теория строится моделью в момент открытия шага (по трём фрагментам по 600 знаков), задания генерируются по требованию. Это медленно, платно и не опирается на все источники. Граф должен быть самодостаточным: всё для изучения узла готово заранее.

Что делаем:
- Сборка узла — один запрос к модели на понятие, когда меняется набор его принятых утверждений (по хешу набора). Модель только раскладывает утверждения по разделам (определение, зачем нужно, как устроено, примеры, типичные ошибки) и связывает предложения; у каждого предложения — ссылки на номера утверждений. Новых фактов вне утверждений модель добавлять не может: предложение без ссылки отбрасывается.
- В той же сборке — банк учебных материалов узла: карточки для повторения, тесты с выбором ответа (неверные варианты — из типичных ошибок), задания с пропуском, задания на порядок. У каждого — ключ ответа, проверка без модели.
- Содержимое и банк хранятся с версией понятия; при новой версии старые задания обесцениваются (как кэш заданий сейчас).
- Новый источник, который только подтвердил известное, добавляет ссылку и не пересобирает теорию.
- При обучении модель не вызывается: теория, ссылки, карточки и тесты читаются готовыми. Модель остаётся только для открытых ответов (эссе, код, устный ответ) и личных материалов человека.

Готово, когда: открытие шага и прохождение карточек и тестов по узлу не делают ни одного запроса к модели; у каждого предложения теории есть ссылка на утверждение и через него — на место в источнике.
