# 00 — Продукт

Раздел отвечает на вопрос **«зачем»**. Всё, что ниже по цепочке (требования, спеки, планы), должно выводиться отсюда. Возможность, которую нельзя обосновать видением или метрикой, в продукт не входит.

| [scope.md](./scope.md) | Границы продукта: что входит, что нет, главная гипотеза, этапы |
| [personas.md](./personas.md) | Кто пользуется системой и что ему нужно |
| [metrics.md](./metrics.md) | Как поймём, что работает: метрики эффективности и продукта |
