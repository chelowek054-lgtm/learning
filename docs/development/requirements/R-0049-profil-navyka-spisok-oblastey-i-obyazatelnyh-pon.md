# Профиль навыка: список областей и обязательных понятий по цели и уровню

Зачем: граф нового навыка строится одним запросом и выходит фиксированного небольшого размера, что не отражает то, что человеку на самом деле нужно знать (эталон — ~48 понятий на 9 этапов).
Что делаем: по цели и уровню модель составляет список областей и обязательных понятий — полное описание навыка; человек видит список и может его поправить до того, как по нему начнётся построение или дополнение графа.
Чего не делаем: не решаем, как список превращается в граф, и не задаём минимальное число понятий на уровень — заметка называет эталонные ~48 только для продвинутого уровня одной области.
Готово когда: для одной цели на разных уровнях список различается по объёму, виден человеку и принимает его правки перед построением графа.
