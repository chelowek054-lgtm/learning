# Задача на код с ревью по рубрике

Зачем: закрыть продукцию кода тем же циклом, что письмо — решение → оценка по рубрике → коррекция. Система обязана: давать задачу из узла графа (практика apply/create) или материала с условием, сигнатурой и примерами; сохранять решение офлайн в редакторе; ревьюить статически (код не исполняется на сервере) по рубрике ml_code_review (Correctness, Efficiency, Style, Explanation), честно показывая ограничение «код не исполнялся»; отправлять ошибки в повторение. Готово, когда: решение получает ревью по 4 критериям и ошибки уходят в повторение (live), AC-16.1.
