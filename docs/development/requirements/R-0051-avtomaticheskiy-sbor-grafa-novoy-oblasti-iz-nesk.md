# Автоматический сбор графа новой области из нескольких источников

Зачем: эталон собран из нескольких источников со связями между этапами и областями, а сейчас поиск источника и разбор документа запускает вручную администратор по одному источнику.
Что делаем: когда область не найдена по близости, система сама ищет несколько источников по области, разбирает каждый и объединяет понятия между собой — со связями этапов/областей и ссылкой на источник у понятия.
Чего не делаем: не определяем, сколько источников на область достаточно и как разрешать противоречия между ними — заметка отмечает, что конфликты уже встречаются, но правило не называет.
Готово когда: для области, которой нет в реестре, граф строится из нескольких источников без ручного запуска, понятия объединены, связи этапов/областей проставлены.
