# Сопоставление области с реестром по косинусной близости вектора

Зачем: понятия уже сравниваются по вектору и сливаются по близости, а области реестра сводятся только по названию и алиасам — область с иным названием, но тем же смыслом, не находится.
Что делаем: область из профиля навыка сравнивается с реестром по вектору с порогом близости; результат — сопоставлена с существующей (с видимым порогом и решением) либо помечена новой.
Чего не делаем: не фиксируем порог близости и не решаем, кто разрешает спорные случаи — заметка это не определяет.
Готово когда: область-синоним без заведённого алиаса находится по вектору, а не только по строке; решение видно человеку.
