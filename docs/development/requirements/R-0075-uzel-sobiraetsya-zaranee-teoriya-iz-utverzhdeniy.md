# Узел собирается заранее: теория из утверждений и банк заданий, обучение без модели

Зачем: теория строится при открытии шага по трём фрагментам, задания — по требованию: медленно, платно, без опоры на все источники.
Что нужно: сборка узла — один запрос на понятие при изменении набора принятых утверждений (по хешу); модель раскладывает утверждения по разделам, у каждого предложения — ссылки на утверждения, предложение без ссылки отбрасывается. В той же сборке — карточки, тесты с выбором (неверные варианты из типичных ошибок), задания с пропуском и на порядок, с ключами ответа. Хранится с версией понятия. При обучении модель не вызывается, кроме открытых ответов и личных материалов.
Готово, когда: открытие шага, карточки и тесты по узлу не делают ни одного запроса к модели; у каждого предложения теории есть ссылка на утверждение.
