# Источники видят только администраторы

Зачем: правовой риск и чистота изложения. Ссылка на источник, файл из хранилища и фрагмент доступны только администраторам и специалистам; учащийся видит изложение и статус, но не источник.
Готово, когда: тестом подтверждено, что обычный пользователь не получает ссылок и фрагментов ни в одном ответе API, доступ к файлам идёт по временным подписанным ссылкам.
