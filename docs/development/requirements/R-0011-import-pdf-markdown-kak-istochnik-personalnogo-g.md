# Импорт PDF/Markdown как источник персонального графа

Зачем: дать собственным материалам учащегося стать источником графа, заземляя узлы на реальный текст, а не облако LLM. Система обязана: принимать PDF/Markdown до 20 МБ, извлекать текст с разбивкой на фрагменты; предлагать по материалу узлы и рёбра персонального слоя со ссылками на фрагменты (source='material'); порождать вопросы concept_recall из материала. Готово, когда: PDF превращается в материал, читаемый офлайн, узлы персональные со ссылками на фрагменты (тест), AC-16.2..3.
