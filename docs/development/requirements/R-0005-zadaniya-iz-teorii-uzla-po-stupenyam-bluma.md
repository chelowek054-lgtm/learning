# Задания из теории узла по ступеням Блума

Зачем: порождать проверку понимания не «из воздуха», а из теории конкретного узла — меньше галлюцинаций, воспроизводимость, дистракторы из реальных заблуждений. Система обязана: генерировать задания по узлу, ступени Блума (remember/understand для test, apply/analyze/evaluate/create для practice, любая для probe) и форме, отсекая узлы без пригодной теории (409); кэшировать по (узел, версия, ступень, форма), обесценивая кэш при правке теории; оценивать закрытый вопрос локально по варианту, открытый — LLM по эталону узла с score 0..1. Готово, когда: признаки подтверждены test_assessment*.py и живым прогоном на RouterAI.
