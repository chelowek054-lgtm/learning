# AI-gateway: единая точка вызова LLM, версия рубрик, учёт стоимости

Зачем: держать все вызовы LLM в одной точке backend — безопасность ключей, версионирование критериев, контроль стоимости, смена провайдера без правки кода. Система обязана: без ключа работать на детерминированной заглушке (MockAIGateway); структурировать результат по JSON-схеме через вызов инструмента; хранить рубрики версионированными данными, оценка помнит версию; учитывать расход токенов по пользователю и типу задачи; не оплачивать повторную детерминированную генерацию дважды (кэш по хэшу входа); сидить рубрики на свежей базе без ручного seed. Готово, когда: все перечисленные признаки проверены тестами (test_openai_gateway, test_usage, test_llm_cache).
