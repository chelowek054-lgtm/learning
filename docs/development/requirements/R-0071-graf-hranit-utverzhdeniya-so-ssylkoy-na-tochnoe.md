# Граф хранит утверждения со ссылкой на точное место в источнике

Зачем: сверка целых понятий не ловит расхождения в отдельных фактах, а теория без ссылок не проверяется.
Что нужно: утверждение (вид, текст, вектор, статус, область применимости, дата актуальности) у понятия; ссылка утверждения на фрагмент с дословной цитатой и смещениями; у фрагмента — страница, заголовок, смещения и адрес с якорем. Извлечение возвращает утверждения; цитата сверяется без модели, без найденной цитаты утверждение отбрасывается.
Нынешний граф — тестовые данные, пересобирается без миграции.
Готово, когда: у каждого опубликованного понятия есть утверждения, у каждого утверждения — проверенная ссылка на место в источнике.
