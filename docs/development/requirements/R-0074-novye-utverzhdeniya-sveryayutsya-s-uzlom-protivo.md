# Новые утверждения сверяются с узлом, противоречия — в пул проблем

Зачем: правило «в узле нет расхождений» проверяется по утверждениям и без лишних запросов к модели.
Что нужно: один запрос на узел на пачку добавлений в фиксированном формате (список принятых утверждений с номерами и добавляемые); ответ по каждому добавляемому — «совпадает с №», «нейтрально» или «противоречит №» с объяснением. Совпадает — новый источник у принятого; нейтрально — новое утверждение; противоречит — проблема в пуле для администраторов с обоими утверждениями и цитатами. Утверждение с открытой проблемой не попадает в теорию и задания.
Готово, когда: добавление источника к узлу даёт один запрос сверки; противоречие видно в пуле; спорное утверждение не видно учащемуся.
