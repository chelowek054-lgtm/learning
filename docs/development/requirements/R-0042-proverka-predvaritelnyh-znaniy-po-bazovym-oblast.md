# Проверка предварительных знаний по базовым областям перед построением курса

Зачем: не учить то, что человек уже знает, и не пропускать то, без чего не понять цель. Модель называет обязательные базовые области, человек проходит короткий тест сверху вниз по цепочке, результат — освоенность в профиле; ответы сверяются с графом (хватает, мало, нет).
Готово, когда: тест можно пропустить, по итогам есть список областей «хватает / мало / нет», проверка идёт по графу областей.
