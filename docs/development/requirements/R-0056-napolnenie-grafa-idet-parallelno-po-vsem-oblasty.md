# Наполнение графа идёт параллельно по всем областям с видимым статусом

Зачем: после graph-build-background-and-visibility.md фоновый запуск сборки уже работает, но осталось нерешённым — области наполняются по 4 за раз вместо всех сразу, статус общий («строится»), а не по каждой области, прерванная сборка (например, из-за перезапуска сервера) не подхватывается сама.
Готово, когда: все области наполняются параллельно; по каждой виден статус «ждёт / в работе / готово»; первая готовая область открывается для работы, не дожидаясь остальных; при повторном входе после прерывания человек видит результат или причину сбоя без ручного перезапуска.
