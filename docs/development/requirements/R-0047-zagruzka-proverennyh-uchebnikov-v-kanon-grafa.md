# Загрузка проверенных учебников в канон графа

Зачем: базовые предметы (математика, языки, программирование) должны строиться из проверенных учебников. Администратор или специалист загружает PDF с метаданными; оглавление даёт скелет, понятия берутся из фрагментов со страницами, результат — черновик до подтверждения.
Готово, когда: PDF с текстовым слоем даёт понятия со страницами, повторная загрузка не дублирует, скан без текста — понятная ошибка, прогресс разбора виден.
