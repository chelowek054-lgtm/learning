# Курс по графу и прохождение шага

Зачем: провести учащегося от карты освоенности к цели путём, повторяющим естественное углубление в предмет, замкнув петлю задание→ответ→освоенность→граница. Система обязана: строить курс стадиями (укоренение ядра, дифференциация в ЗБР, ветвление по интересу, спираль); давать под каждый узел цепочку активностей с нарастанием ступени, контрастом заблуждений и вкраплённым повторением; разворачивать шаг в Activity, писать ответ в response, двигать освоенность; закрывать шаг только по достигнутой освоенности (estimate ≥ 0.75, confidence ≥ 0.6), а не кнопкой; сохранять пройденное при пересборке курса. Готово, когда: признаки FR-CRS-01..05 подтверждены test_course.py/test_study.py и живым прогоном.
