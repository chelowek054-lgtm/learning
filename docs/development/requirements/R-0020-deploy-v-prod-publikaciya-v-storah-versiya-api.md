# Деплой в прод, публикация в сторах, версия API

Зачем: превратить стенд в развёрнутый продукт с managed Postgres, секретами из окружения и доставкой исправлений. Система обязана: поднимать staging из main с миграциями до старта API; отказываться стартовать с dev-секретами в staging/prod; версионировать API префиксом /v1 с проверкой совместимости клиента; публиковаться в App Store и Google Play через EAS Build и доставлять JS-исправления через EAS Update. Готово, когда: признаки FR-PRD-01..02 подтверждены live на проде.
