# Политика данных: хранение, сроки, согласие, удаление аккаунта

Зачем: превратить работающий стенд в продукт, которому можно доверить данные людей. Система обязана: документировать, какие данные хранятся где и сколько и кто из провайдеров их видит; удалять данные по срокам политики периодической задачей; получать согласие с политикой при регистрации с версией у пользователя; удалять все строки пользователя при удалении аккаунта, оставляя только анонимизированную статистику. Готово, когда: признаки FR-AUTH-08, FR-PRD-03 подтверждены тестом.
