# Адаптивный плейсмент по графу

Зачем: быстро понять, где учащийся находится в графе, чтобы курс не начинался ни с известного, ни с непосильного. Система обязана: начинать с выбора учащимся целевого уровня; подбирать зонд на границе знаний с учётом неопределённости и centrality, не зондируя узлы с неосвоенными предпосылками; обновлять освоенность по ответу; останавливаться с кодом причины (empty/no_theory/settled) и отдавать карту known/frontier/learning/locked. Готово, когда: признаки FR-PLC-01..04 подтверждены test_placement.py/test_mastery.py и живым прогоном (12 зондов, 2026-08-23).
