# Администрирование и курирование канона

Зачем: дать куратору инструменты, которые не дадут канону «поплыть» — вычитку LLM-черновиков, тир, версию теории, промоцию лучших персональных узлов. Система обязана: пускать в /admin только is_superuser с закрытием доступа той же сессии при снятии флага; давать таблицы всех модулей с фильтрами, поиском, экспортом CSV; давать CLI createsuperuser интерактивно и без интерактива; позволять администратору поднять качественный персональный узел в канон с переносом версии и снятием оверрайда у автора. Готово, когда: не-админ не входит в /admin; createsuperuser создаёт/повторяет/повышает; промоция работает.
