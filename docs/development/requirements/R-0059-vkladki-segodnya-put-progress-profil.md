# Вкладки «Сегодня», «Путь», «Прогресс», «Профиль»

Зачем: «Курс» и «Граф» — два взгляда на один путь без видимой связи между ними; «Прогресс» спрятан в настройках; «Профиль» — список из пятнадцати разных по смыслу карточек.
Что делаем: четыре вкладки — «Сегодня», «Путь», «Прогресс», «Профиль». «Путь» объединяет шаги курса и карту знаний переключателем «Шаги/Карта» и включает «Состав навыка» и «Откуда знания» (материалы). «Прогресс» — отдельная вкладка. Предмет переключается из шапки «Сегодня», «Пути» и «Прогресса»; «Сменить предмет» не сбрасывает онбординг. Уведомление открывает тот экран, о котором оно, а не всегда «Сегодня».
Чего не делаем: не меняем содержимое самих экранов (шаг курса, повторение, определение уровня) — только расположение; не вводим несколько предметов одновременно.
Готово, когда: в приложении четыре вкладки с описанным содержимым, переключение предмета из шапки трёх вкладок не сбрасывает онбординг, уведомление ведёт на свой экран.
