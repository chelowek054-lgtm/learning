# «Сегодня» отражает все состояния предмета, а не только курс и повторение

Зачем: сейчас `nextAction` (learningFront/src/pages/home/model/next-action.ts) в последней ветке всегда предлагает «Определить уровень», даже если у предмета ещё нет графа вовсе — свидетельство из user-flow-as-is-problems.md, п.1. По таблице состояний из user-flow-daily-loop.md у предмета должно быть различимое «Сегодня» для: нет предмета, цель ставится, состав навыка показан, карта собирается, сборка не удалась, карта готова но уровень неизвестен, идёт путь, путь пуст есть повторение, цель достигнута, на паузе.
Готово, когда: для каждого из этих состояний `nextAction` возвращает свой вид и это покрыто тестом; ни одно состояние не подменяется «Определить уровень» по умолчанию.
