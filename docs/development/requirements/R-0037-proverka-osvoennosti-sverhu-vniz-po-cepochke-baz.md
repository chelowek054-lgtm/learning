# Проверка освоенности сверху вниз по цепочке базовых областей

Зачем: по умолчанию строится полная цепочка базовых областей в предположении, что человек ничего не знает; лишнее отсекается проверкой уровня сверху вниз по ключевым узлам каждой области (знает производные — ниже не проверяем), иначе взрослый и второклассник получают одинаково длинный путь.
Готово, когда: проверка уровня работает по нескольким подключённым областям подряд, идёт от сложных к простым, и освоенный верхний узел снимает проверку нижестоящих; путь человека начинается с самой нижней неосвоенной области.
