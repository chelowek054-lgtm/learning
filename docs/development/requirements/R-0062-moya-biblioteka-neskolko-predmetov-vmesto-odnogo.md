# «Моя библиотека»: несколько предметов вместо одного в профиле

Зачем: predmet хранится единственным значением, смена сбрасывает онбординг, два предмета параллельно вести нельзя. Нужно: предмет человека — запись с состоянием (собирается/идёт/пауза/достигнута цель); экран «Моя библиотека» — добавить, открыть, поставить на паузу, удалить предмет; открытие ведёт в «Сегодня/Путь/Прогресс» этого предмета; активный предмет запоминается, шапка вкладок ведёт в библиотеку вместо прямого переключателя; очередь повторения остаётся общей для всех предметов, но с подписью предмета на карточке. Готово когда: человек с двумя предметами видит оба в библиотеке, переключается без сброса онбординга, очередь повторения показывает карточки обоих с подписью предмета.
