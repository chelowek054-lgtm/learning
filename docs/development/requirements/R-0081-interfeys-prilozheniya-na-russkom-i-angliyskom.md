# Интерфейс приложения на русском и английском

Зачем: строки клиента зашиты по-русски, сервер отдаёт русские тексты ошибок и уведомлений.
Что нужно: словари строк ru и en, экраны берут строки по ключу (в духе A-0018); множественное число по правилам языка; язык по умолчанию — язык устройства, иначе английский; переключатель в профиле, выбор запоминается; язык интерфейса и язык изучения — разные настройки; даты и числа по языку; сервер отдаёт коды, текст выбирает клиент; уведомления — на языке пользователя; генерация моделью получает язык явно.
Готово, когда: все экраны переключаются без перезапуска; ключи словарей совпадают; ошибки и уведомления приходят на языке пользователя.
