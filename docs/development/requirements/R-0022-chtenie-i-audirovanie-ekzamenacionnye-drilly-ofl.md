# Чтение и аудирование: экзаменационные дриллы офлайн

Зачем: закрыть рецептивные навыки экзаменационным форматом на время — проверка детерминирована и работает без сети, разбор ошибок догоняет при сети. Система обязана: давать reading-дрилл (passage, MCQ/T-F-NG/пропуск, таймер, мгновенный локальный результат) и listening-дрилл (закэшированное аудио, лимит прослушиваний, понятное объяснение при отсутствии в кэше) офлайн; давать разбор дистракторов при сети без блокировки прохождения; генерировать материалы (passage, вопросы, озвучка) с курированием draft/approved. Готово, когда: признаки FR-RCP-01..05 подтверждены на устройстве.
