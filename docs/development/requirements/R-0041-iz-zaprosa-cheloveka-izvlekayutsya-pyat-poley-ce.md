# Из запроса человека извлекаются пять полей цели

Зачем: свободный запрос «хочу изучить X до уровня Y, потому что…» должен давать структуру, от которой зависят граф и курс. Поля: область, целевой уровень, зачем, что уже знает, ограничения (срок, время, формат).
Готово, когда: любой запрос даёт значения или явное «не указано» для пяти полей, подтверждённая цель хранит их структурно и передаёт построению; без сети есть прямая форма с теми же полями.
