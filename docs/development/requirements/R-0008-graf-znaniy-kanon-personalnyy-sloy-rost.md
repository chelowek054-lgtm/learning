# Граф знаний: канон, персональный слой, рост

Зачем: сделать структуру предмета явной — граф понятий с теорией, общий для всех (канон) и растущий под каждого (персональный слой), как основу плейсмента, курса и генерации заданий. Система обязана: отдавать эффективный граф без копирования строк новому пользователю; давать построить пустую область LLM-черновиком любому пользователю (status='draft'), а достройку/перегенерацию — только администратору; давать администратору курировать канон (правка, ребро, approve, пересчёт centrality); давать учащемуся перекрывать теорию, заводить свои узлы/рёбра и растить ветку от узла (expand). Готово, когда: признаки FR-KG-01..06 подтверждены (test_cow, test_graph_access, test_centrality, test_content).
