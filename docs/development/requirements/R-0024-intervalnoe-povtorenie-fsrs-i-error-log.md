# Интервальное повторение (FSRS) и error-log

Зачем: удерживать факты и понятия интервальным повторением и связать его с продукцией — ошибки становятся карточками. Система обязана: повторять карточки офлайн с FSRS-пересчётом due_at без сети; показывать очередь «к повторению сегодня»; превращать ошибки оценённой продукции и слабые ответы шага курса в карточки с опциональной привязкой к узлу; подбирать стартовую колоду по предмету (AWL для языковых); держать единственный, одинаково объявленный на клиенте и backend тип SRS-активности. Готово, когда: признаки FR-SRS-01..06 подтверждены; FR-SRS-06 ещё не начат (см. d-srs-card-queue).
