# Письмо IELTS Task 2 с AI-оценкой

Зачем: проверить главную гипотезу продукта — AI-оценка эссе по официальным критериям с разбором ошибок, которые затем тренируются повторением. Система обязана: давать писать эссе Task 2 со счётчиком слов, сохраняя офлайн; сразу показывать черновой офлайн-сигнал (объём, абзацы, покрытие AWL), явно помеченный черновым; при сети оценивать по 4 критериям IELTS (0–9) с ошибками и образцом переписанных предложений; отправлять ошибки в повторение. Готово, когда: признаки FR-WRT-01..03 подтверждены live; на устройстве не проверено (P3-DEV-02).
