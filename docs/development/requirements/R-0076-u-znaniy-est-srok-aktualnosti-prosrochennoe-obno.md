# У знаний есть срок актуальности, просроченное обновляется

Зачем: часть знаний устаревает (API, версии, цифры, нормы, практики), граф не должен учить устаревшему.
Что нужно: класс изменчивости утверждения (устойчивое, медленное 2–3 года, быстрое 6–12 месяцев) ставится при извлечении в том же запросе, по умолчанию — областью; даты «актуально на» и «пересмотреть после»; плановая задача без модели ставит просроченные узлы на обновление (поиск новых источников). Новый источник не ниже по доверию против быстрого утверждения — замена с историей; для остальных классов — в пул. Утверждения с разной областью применимости не противоречат. Учащийся видит «актуально на»; заменённое возвращает узел в повторение. Ссылки периодически проверяются.
Готово, когда: у утверждений есть класс и дата пересмотра; просроченные узлы сами встают на обновление; замена видна в истории.
