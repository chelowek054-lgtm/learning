# Теория понятия из разделов вместо абзаца-пересказа

Зачем: нынешний текст теории — пересказ определения на 2–3 предложения без примеров, разбора ошибок и связи с соседями, учить по такому нельзя. Нужно: при открытии понятия в шаге курса доступна теория из разделов (определение простыми словами; зачем нужно и где встречается; как устроено; пример с разбором; типичные ошибки; связь с соседями) объёмом на экран-два, подобранная под уровень цели человека и уровень понятия. Если у понятия есть источник — теория опирается на его фрагменты и это видно («по источнику»); без источника — честная пометка «составлено автоматически, не проверено». Теория не готовится заранее для всего графа — создаётся при первом открытии понятия в шаге или фоном для ближайших шагов, сохраняется в понятии (версия растёт, кэш заданий обесценивается, как при правке куратором). Готово когда: открыв шаг курса для понятия без готовой теории, человек видит разделы на экран-два, с пометкой источника или «не проверено», и задания шага строятся по этой теории, а не по одному summary.
