# Устная речь: запись, распознавание, оценка по рубрике

Зачем: закрыть последний тип продукции — устную речь — тем же циклом, что письмо: ответ → оценка по рубрике → разбор → ошибки в повторение. Система обязана: записывать ответ офлайн с прослушиванием до отправки; загружать запись при сети с лимитами и удалять с устройства после загрузки; распознавать речь отложенной задачей (заглушка без ключа), честно сообщая об ошибке на пустой/тихой записи; оценивать по рубрике ielts_speaking (4 критерия, band), честно помечая ограничение оценки произношения по тексту STT; отправлять ошибки речи в error-log; хранить записи на сервере по политике данных. Готово, когда: признаки FR-SPK-01..06 подтверждены на устройстве.
