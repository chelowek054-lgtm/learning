# Работа с нескольких устройств без потери прогресса

Зачем: сейчас принят один активный девайс и LWW (d-offline-first); для продукта нужна стратегия сверх этого. Система обязана: сходиться при повторениях на двух устройствах без отката интервалов FSRS (слияние srs_card по последнему ревью, а не по времени записи); response остаётся иммутабельным без конфликтов. Готово, когда: признак FR-SYNC-07 подтверждён тестом.
