# Полный профиль навыка, области и граф из нескольких источников

Зачем: граф под цель человека должен быть полным, а не набросанным моделью из памяти на восемь понятий. Модель описывает, что нужно знать на 100% для навыка и уровня, делит это на области и этапы; профиль сопоставляется с графом по близости векторов; чего нет — строится из нескольких источников и сводится в один граф.
Готово, когда: по цели и уровню есть профиль (области, этапы, понятия с уровнем сложности и пометкой «необязательно», связи), человек видит его и может поправить; каждая область и понятие либо сопоставлены с имеющимися, либо помечены новыми; новая область строится из нескольких источников и сливается со скелетом профиля; размер графа зависит от цели и уровня; отчёт полноты показывает, чего из профиля в графе ещё нет.
