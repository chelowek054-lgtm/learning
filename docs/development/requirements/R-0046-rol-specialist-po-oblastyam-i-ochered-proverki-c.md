# Роль «специалист» по областям и очередь проверки черновиков

Зачем: проверка содержания требует людей с квалификацией по области, а сейчас есть только флаг суперпользователя. Роль назначается на области; очередь проверки показывает новые и изменённые понятия с источником, уверенностью модели и противоречиями; действия — подтвердить, исправить, отклонить с причиной; журнал решений.
Готово, когда: специалист видит и правит только свои области, каждое решение записано (кто, когда, что).
