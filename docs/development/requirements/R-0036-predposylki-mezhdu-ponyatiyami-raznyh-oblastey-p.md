# Предпосылки между понятиями разных областей по ступени освоения

Зачем: подтягивать нужно не всю базовую область, а только предков конкретных узлов — для градиентного спуска нужны «наклон», «производная», «частная производная» и то, что под ними, а не весь матанализ; к тому же разным целям нужна разная глубина («понять своими словами» — интуиция наклона, «решить задачу» — производные).
Готово, когда: связь-предпосылка хранится между понятиями (не областями целиком) и помечена ступенью освоения, с которой обязательна; курс при сборке подтягивает из базовых областей только предков, нужных для целевых узлов и выбранной ступени цели.
