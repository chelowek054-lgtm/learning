# ML-трек: чтение материала и вспоминание понятия

Зачем: доказать вторичную гипотезу — тот же движок Activity без изменений обслуживает технический предмет (прочитал → вспомнил своими словами → получил проверку → слабое ушло в повторение). Система обязана: давать читать материал офлайн; давать объяснить понятие своими словами и получить AI-проверку по рубрике concept_check (Correctness, Completeness, Explanation), неточности — в SRS. Готово, когда: признаки FR-ML-01..02 подтверждены живым прогоном; на устройстве сценарий не проверен (P3-DEV-02).
