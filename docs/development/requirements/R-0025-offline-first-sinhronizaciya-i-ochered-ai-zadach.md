# Offline-first синхронизация и очередь AI-задач

Зачем: всё, что человек делает, должно работать без сети, а всё, что требует LLM, — исполняться при её появлении без потерь и дублей. Система обязана: писать ответы и повторения в локальный SQLite без сети; синхронизироваться двумя фазами (push, затем pull), идемпотентно по id на пользователя; ставить AI-задачи в очередь офлайн и исполнять при сети (pending→running→done/failed); запускать sync сама при появлении сети и возврате в приложение, не только вручную; отдавать в pull только изменения с прошлого sync; повторять неудачную задачу с отсрочкой, помечая failed с причиной после лимита попыток. Готово, когда: признаки FR-SYNC-01..08 подтверждены; авто-триггер и since ещё не сделаны.
