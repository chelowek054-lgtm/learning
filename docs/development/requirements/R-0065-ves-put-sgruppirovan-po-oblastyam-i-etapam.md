# «Весь путь» сгруппирован по областям и этапам

Зачем: плоский список из 181 шага неудобен, области и этапы не видны. Нужно: «Весь путь» группируется аккордеоном область → этап → шаги по порядку; верхний уровень — название области, число шагов, «пройдено N из M»; открыт по умолчанию только текущий этап, остальные свёрнуты; «Сейчас» всегда видно сверху; состояние свёрнутости запоминается между заходами. Названия без служебных слов («Черновик» → «не проверено», «Основа» → «обязательное»). Готово когда: открыв «Путь» с несколькими областями и этапами, человек видит группы, а не сплошную ленту, может свернуть/развернуть группу, и состояние остаётся после перезахода.
