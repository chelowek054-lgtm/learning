# Доставка уведомлений о курсе вне приложения (push)

Регистрация токена устройства, отправка push при создании уведомления, согласие и отключение, текст без содержания источников, сбой канала не ломает сборку курса.

## Журнал

- 2026-10-06 · заведена из docs/inbox/task-push-notifications.md · приложение
- 2026-10-06 · взята в работу, сделана (learningBack PR 57, learningFront PR 31): выбран Expo Push (работает с EAS-сборкой, прячет FCM и APNs; провайдер сменяем отдельным классом); таблица устройств (миграция 0030), регистрация токена = согласие, настройка «присылать» отключает все устройства, выход из аккаунта на устройстве удаляет токен, удаление аккаунта стирает устройства (проверено); при создании нового уведомления в очередь ставится отправка (накопление непрочитанного не шлёт повторно), в inline-режиме пробуется сразу; текст push — только вид уведомления и область, без названий понятий и источников; сбой провайдера не ломает сборку курса, задача повторяется по правилам очереди, постоянная ошибка завершает её, недействительный токен удаляется; в профиле карточка «Уведомления» с честными причинами отказа (нет разрешения, нет EAS-проекта, не телефон); в data-policy внесены токены и Expo
- 2026-10-06 · на проверку: 17 тестов бэкенда, полный набор бэкенда и тесты клиента проходят; не проверено: получение токена и доставка на реальном телефоне — для этого нужна сборка через EAS и projectId (T-0034), в Expo Go токен не выдаётся; живой отправки через Expo не было · claude
- 2026-10-06 · остаётся на проверке: V-0095 прошла в отчёте, но доставка на реальный телефон не проверена (нужна EAS-сборка, T-0034) · claude
