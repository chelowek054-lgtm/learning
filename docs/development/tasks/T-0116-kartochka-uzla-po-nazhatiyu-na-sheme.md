# Карточка узла по нажатию на схеме

Нажатие на узел открывает карточку без выхода со схемы: пояснение понятия, соседи «нужно раньше / открывает», состояние освоения, кнопка «Изучать» (ведёт в шаг курса), для личного узла — инлайн-правка.
