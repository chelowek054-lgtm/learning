# Тест предварительных знаний и отчёт о покрытии графа

Короткий тест по базовым областям цели сверху вниз, запись освоенности в профиль, отчёт по областям: хватает, мало, нет.

## Журнал

- 2026-10-06 · заведена из docs/inbox/requirement-prior-knowledge-test.md · приложение
- 2026-10-06 · взята в работу, сделана (learningBack PR 53, learningFront PR 28): отчёт по базовым областям цели сверху вниз — по каждой «хватает / мало / нет», «не проверено» (вас не спрашивали) и «нет в графе» (области в графе нет вообще, сверять не с чем, список недостающих отдаётся отдельно); для областей считаются нужные понятия, освоенные и черновые; ответ на зонд цепочки записывает освоенность в профиль и сразу возвращает следующий зонд и обновлённый отчёт; тест можно пропустить — все области остаются «не проверено», курс строится как для новичка (проверено тестом); на экране «Определить уровень» новый режим «Базовые области»: выбор ступени, тест или «Пропустить», отчёт
