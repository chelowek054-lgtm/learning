# Пять полей цели в диалоге постановки цели

Расширить диалог цели до пяти полей (область, уровень, зачем, что знает, ограничения), хранить структурно, передавать построению; прямая форма без сети с теми же полями.

## Журнал

- 2026-10-06 · заведена из docs/inbox/requirement-goal-five-fields.md · приложение
