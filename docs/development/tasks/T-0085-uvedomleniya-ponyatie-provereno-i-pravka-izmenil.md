# Уведомления «понятие проверено» и «правка изменила смысл пройденного»

Подтверждение понятия уведомляет тех, кто по нему учится, и снимает пометку «Черновик» без перезапуска шага; правка со сменой смысла уведомляет прошедших понятие; уведомления копятся, а не дублируются.

## Журнал

- 2026-10-06 · заведена из docs/inbox/task-notify-concept-verified-and-changed.md · приложение
- 2026-10-06 · взята в работу, сделана (learningBack PR 56, learningFront PR 30): при подтверждении понятия (только при переходе в «проверено», повторное подтверждение молчит) уведомление получают все, у кого оно в пути курса, и пометка «проверено» сразу ставится в уже выданных заданиях шага (уходит при синхронизации, без перезапуска шага); при правке изложения уведомление получают только те, кто понятие уже прошёл, с текстом, что изменилось, и советом повторить шаг; переименование смысла не меняет и не уведомляет; непрочитанные уведомления одного вида копятся в одно (названия понятий, «и ещё N»); отклонение не уведомляет; на экране курса новые виды показываются карточками, правка пройденного — предупреждением
- 2026-10-06 · на проверку: 13 тестов (подтверждение, повтор, отклонение, накопление, статус в заданиях, правка, переименование, API), полный набор бэкенда и тесты клиента проходят; не сделано: журнал изменений понятия для человека (вопрос из R-0044 остаётся открытым), содержание уже выданного задания не обновляется — только статус, доставка вне приложения (T-0086), экран на телефоне не проверялся · claude
