# Длинные связи меткой-счётчиком и свёртка «призраков» выбранного понятия

У выбранного понятия — только прямые связи; соседи из свёрнутых этапов — «призраками» с подписью этапа, больше 8 сворачиваются в блок «ещё N из этапа Х»; кнопка «Вся цепочка» разворачивает все предпосылки. Длинные связи (через колонку и дальше) без выбора заменяются меткой-счётчиком на узле. Расширяет уже реализованный фокус на понятии (T-0133), не заменяет его.
