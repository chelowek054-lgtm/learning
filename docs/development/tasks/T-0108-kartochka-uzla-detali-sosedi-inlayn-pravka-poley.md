# Карточка узла: детали, соседи, инлайн-правка полей

Клик по узлу открывает боковую карточку: название, пояснение, тир, статус, этап, уровень, версия, источники, соседи «нужно раньше/открывает»; правка названия, пояснения, тира, статуса, этапа, уровня, необязательности прямо в карточке; версия растёт при смене содержимого (как и в текущей админке).
