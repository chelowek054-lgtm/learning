# Поиск источников по белому списку и через веб-поиск

Поиск по каталогам белого списка, API поиска для недостающего, метаданные происхождения, лимиты запросов и скачивания.

## Журнал

- 2026-10-06 · заведена из docs/inbox/decision-source-rules.md, docs/inbox/decision-web-search-provider.md · приложение
- 2026-10-06 · взята в работу, сделана (learningBack PR 49 и 50): `modules/knowledge/source_search.py` — поставщики Wikibooks (MediaWiki API, CC BY-SA, пустые заготовки отсекаются, текст из викитекста в Markdown с главами), arXiv (Atom API, PDF статьи), веб-поиск Brave (только при ключе BRAVE_API_KEY, запрос ограничен разрешёнными сайтами); белый список доменов в SOURCE_DOMAINS (по умолчанию wikibooks, openstax, libretexts, arxiv, gutenberg, docs.python.org; поддомены разрешены, домен-двойник вроде wikibooks.org.evil.com нет); скачивание: чужой домен отклоняется без единого запроса, каждый редирект проверяется по белому списку, лимит размера по заголовку и по потоку, таймаут, не больше трёх переходов; на запрос не больше 3 документов, известный адрес пропускается, нечитаемый файл не останавливает остальные; у документа сохраняются адрес, лицензия и поставщик, разбор ставится в очередь, источник удаляется вместе с выведенным (T-0076); админский API: поиск без скачивания и скачивание выбранного с повторной проверкой домена
