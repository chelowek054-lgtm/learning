# Каркас схемы графа пути: узлы, рёбра, раскладка по этапам и уровням, масштаб

Вкладка «Путь» получает переключатель «Карта»: холст с узлами-понятиями и рёбрами-предпосылками, раскладка слева направо по этапам и внутри этапа по уровню (база/средний/продвинутый), масштабирование и перемещение на телефоне и вебе, свёртка области до одной плашки и разворот обратно, обзор областей для крупных графов (понятия открываются по нажатию на область). Список остаётся отдельным переключателем.
