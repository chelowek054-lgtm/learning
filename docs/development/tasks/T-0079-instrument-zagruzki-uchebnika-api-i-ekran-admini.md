# Инструмент загрузки учебника: API и экран администратора

Форма загрузки PDF с метаданными, скелет из оглавления, прогресс разбора, результат черновиком; повторная загрузка без дублей, понятная ошибка для скана.

## Журнал

- 2026-10-06 · заведена из docs/inbox/requirement-textbook-upload-tool.md · приложение
- 2026-10-06 · взята в работу; сделана серверная часть (learningBack PR 46): POST /graph/sources (файл, область, название, уровень, лицензия, адрес) — только администратору; файл читается до записи в хранилище, скан без текстового слоя и неподдерживаемый формат отклоняются сразу с объяснением и без следов; тот же файл второй раз дубля не создаёт, повторная загрузка после сбоя ставит разбор заново; GET /graph/sources/{id}/progress и список источников отдают состояние разбора (в очереди, идёт, готово, ошибка), окна, число понятий, черновиков и проверенных; тесты проходят · claude
- 2026-10-06 · не сделано: экран администратора в клиенте (форма загрузки через выбор файла, список с прогрессом) — по образцу экрана материалов, виден только при isAdmin; задача остаётся в работе · claude
- 2026-10-06 · сделан экран «Источники знаний» в клиенте (learningFront PR 26): форма загрузки — область (обязательна), название, уровень, лицензия, адрес, выбор файла с полосой отправки; список документов с названием, метаданными, статусом разбора, полосой по окнам и сводкой (понятий, черновиков, проверенных, отброшенных без подтверждения, усечение по лимиту окон), автообновление каждые 5 секунд, пока что-то в очереди или идёт; удаление источника с подтверждением; карточка в профиле видна только администратору, прямой переход по адресу для остальных показывает отказ; понятные ответы на повтор файла и на отказы сервера (скан, формат, размер)
