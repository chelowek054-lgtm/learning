# Реестр модулей и независимость ядра от предметов

Оформление уже сделанной и проверенной работы по R-0002, чтобы требование не висело без задачи (не новая разработка).
Сделано: ядро backend не импортирует предметные модули, подключает их через реестр по `INSTALLED_MODULES` и общий контракт (маршруты, рубрики, типы заданий, стартовый контент, представления админки) — решение A-0001; клиентский реестр диспетчеризует по типу задания без ветвлений по модулю; ядро клиента не содержит предметных слов, цвета — в одном файле оформления; проверки инвариантов идут в CI на каждый push; стартовый контент выдаёт модуль по выбранному предмету.
Код: `core/modules.py`, объекты `backend` модулей, `core/app.py`, `core/jobs.py`, `core/admin.py`, `core/routers/auth.py`; клиент — `shared/engine/module`; `scripts/check-invariants.sh`.
