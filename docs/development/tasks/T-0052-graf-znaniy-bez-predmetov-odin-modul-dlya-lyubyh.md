# Граф знаний без предметов — один модуль для любых областей

Зачем: R-0028 — граф знаний должен быть структурным ядром, общим для технологий, языков и любых других предметов; сейчас выбор предмета и часть стартового контента завязаны на название предмета.
Делаем: убираем из модуля графа проверки по названию предмета, предметные рубрики и предметный стартовый контент; граф отдаёт интерфейс — прочитать узел и связи, найти границу знаний, получить/записать освоенность (свидетельство об освоении), подписаться на изменение узла; проверяем, что один код обслуживает три предмета разной природы (технический, языковой, произвольный), различия — в данных, не в ветвлении; курс и плейсмент опираются на интерфейс графа, не знают о типах заданий.
Не делаем: не встраиваем в граф способы запоминания (он знает уровень освоения, не то, как к нему пришли); не храним в графе данные пользователя.
Готово, когда: тест на трёх разных предметах проходит без ветвления по названию предмета в коде графа.
