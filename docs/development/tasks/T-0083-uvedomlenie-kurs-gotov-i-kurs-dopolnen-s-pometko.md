# Уведомление «курс готов» и «курс дополнен» с пометкой о черновике

Курс собирается из имеющегося и доращивается в фоне; человеку сообщается о готовности и о дополнении с честной пометкой «не проверено специалистом»; статус виден на экранах курса и узла.

## Журнал

- 2026-10-06 · заведена из docs/inbox/requirement-draft-status-and-notify.md · приложение
- 2026-10-06 · взята в работу, сделана (learningBack PR 51 и 52, learningFront PR 27): миграция 0029 (уведомления), «курс готов» ставится при сборке курса (число шагов и сколько из них черновых), «курс дополнен» — всем, у кого есть курс по области, когда разбор документа добавил понятия (и ставит слияние); непрочитанные копятся в одно уведомление, а не плодятся, после прочтения следующее — новое; повторный разбор готового документа не уведомляет второй раз; во всех уведомлениях с черновиками стоит честная пометка «Не проверено специалистом: содержание собрано автоматически»; API списка своих и отметки «прочитано» (чужие не отмечаются); на экране курса карточки с кнопкой «Понятно», на экране понятия пометка «Черновик» (в задании шага есть статус, источника нет)
- 2026-10-06 · на проверку: 14 тестов бэкенда, тесты клиента и полный набор проходят; не сделано: доставка вне приложения (push) — уведомления лежат в базе и показываются на экране курса при открытии; уведомление «понятие проверено» (когда специалист подтвердил то, по чему человек учится) и «правка изменила смысл пройденного» не реализованы; статус в задании шага фиксируется на момент начала шага и не обновляется до следующего начала · claude
