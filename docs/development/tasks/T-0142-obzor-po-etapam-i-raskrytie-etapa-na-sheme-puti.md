# Обзор по этапам и раскрытие этапа на схеме пути

Блоки этапов со счётом освоенности, стрелки-счётчики между этапами с плашкой списка связей по клику, раскрытие этапа на месте с меткой «порт» у понятий со связями наружу, путь «Все этапы › Х» и сводка «опирается/открывает». Включается сам по порогу, переключатель «Этапы/Всё» всегда доступен. Ждёт дизайн-макета (см. grouping-req) — без него не начинается.
