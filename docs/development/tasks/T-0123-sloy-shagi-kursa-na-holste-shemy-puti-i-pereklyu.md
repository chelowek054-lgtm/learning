# Слой «шаги курса» на холсте схемы пути и переключатель «Список/Дерево»

Добавляет на холст схемы графа пути (T-0113…T-0118) слой с шагами курса вместо понятий канона: пройденное/текущее/закрытое как визуальные состояния, карточка шага по нажатию, кнопка «Начать». Переиспользовать готовое нечего — холст из T-0113 ещё не реализован, отсюда прямая зависимость.
