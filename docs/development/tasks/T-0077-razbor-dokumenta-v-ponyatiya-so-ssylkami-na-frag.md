# Разбор документа в понятия со ссылками на фрагмент

Фоновая задача: документ из хранилища → фрагменты → понятия, объяснения, примеры, ошибки и связи со ссылкой на фрагмент; понятие без ссылки не принимается; один разбор на книгу, лимит токенов.
