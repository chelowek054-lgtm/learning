# Экран «Моя библиотека» и запись «предмет человека»

Бэкенд: предмет человека становится записью со состоянием (собирается/идёт/пауза/достигнута цель) вместо одного поля profile.subject — модель и эндпоинты списка/добавления/паузы/удаления. Клиент: экран «Моя библиотека», открытие предмета ведёт на его «Сегодня»; шапка вкладок показывает активный предмет и ведёт в библиотеку (меняет текущее поведение шапки из T-0111 — см. affects у требования). Очередь SRS остаётся общей, на карточке добавляется подпись предмета. Переиспользует: нет готового модуля под несколько предметов — entities/session читает один profile.subject, его придётся расширить, а не писать заново с нуля.
