# Автоматический поиск источников по областям «нет в графе»

Из отчёта по базовым областям администратор одним действием запускает поиск по белому списку и разбор для областей, которых нет в графе; готовый запрос, защита от повторного запуска, источники не раскрываются не администраторам.

## Журнал

- 2026-10-06 · заведена из docs/inbox/task-auto-source-search-for-gaps.md · приложение
- 2026-10-06 · взята в работу, сделана (learningBack PR 55, learningFront PR 29): администратору по цели отдаётся список базовых областей без понятий в графе с готовым запросом (название области, его можно поправить) и ходом разбора их документов; одним действием запускается поиск по белому списку, скачивание и разбор для выбранной области (в ручку нельзя подставить область, которой нет в пробелах цели); повторный запуск по области, пока документы в очереди или разбираются, отклоняется, после завершения разрешён; пустая выдача, слишком короткий запрос и уже загруженное возвращаются понятными статусами; оба маршрута только для администратора (проверено: учащийся получает 403); на экране источников карточка «Чего не хватает в графе» с обновлением по ходу разбора
