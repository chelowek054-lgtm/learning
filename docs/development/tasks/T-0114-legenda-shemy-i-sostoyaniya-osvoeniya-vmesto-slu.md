# Легенда схемы и состояния освоения вместо служебных подписей

Легенда над холстом (сворачиваемая, с запоминанием состояния) расшифровывает цвет/форму/прозрачность. Пройденные понятия приглушены, но на месте; граница изучения подсвечена; закрытые (без предпосылок) выглядят закрытыми; изучаемые — с отметкой прогресса. Служебные подписи вроде c0.149 · inherited заменяются на «база/средний/продвинутый», «необязательное», «не проверено куратором», «своё»; центральность передаётся размером узла.
