# AI-gateway: транспорт, учёт токенов, кэш, рубрики при старте

Оформление уже сделанной и проверенной работы по R-0004 (не новая разработка).
Сделано: провайдер LLM задаётся конфигурацией, одна реализация на любой OpenAI-совместимый сервис, без ключа — детерминированная заглушка (решение A-0009); транспорт повторяет обрыв канала, ответ «не хватает кредита» и ответ текстом вместо инструмента, лимит токенов передаётся в каждом запросе; расход токенов учитывается по пользователю и назначению, сбой учёта не ломает вызов; детерминированные ответы кэшируются по хэшу входа, построение графа не кэшируется; рубрики версионируются и добавляются при старте API без перезаписи существующих.
Код: `core/ai_gateway`, `core/usage.py`, `core/routers/usage.py`, `core/llm_cache.py`, `core/modules.py`, миграции 0009 и 0012. Слито в main (learningBack PR 1).
