# Генерация теории понятия по разделам при открытии шага

При первом открытии понятия, у которого в content только summary, построить разделы теории под уровень цели и уровень понятия; при наличии источника опереться на его фрагменты и пометить «по источнику», иначе — «составлено автоматически, не проверено»; результат сохранить в content узла, поднять версию (как при правке куратором), чтобы кэш заданий (assessment_store.py) обесценился. Не трогает сборку скелета (profile_build.py) и профиль навыка (skill_profile.py) — это отдельный путь. Переиспользует доменную JSON-схему узла с теорией и промпты из modules/knowledge/ai.py (уже умеют строить структурированную теорию при построении темы и дорастании ветки) — вызывает тот же подход по требованию для одного понятия, а не для всего графа.
