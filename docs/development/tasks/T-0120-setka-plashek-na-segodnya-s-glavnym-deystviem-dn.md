# Сетка плашек на «Сегодня» с главным действием дня

Переводит home-screen с одной карточки на сетку плашек; логика главного действия (next-action.ts, R-0057/T-0105) остаётся источником для первой крупной плашки, остальные — новые самостоятельные виджеты (повторение, освоено сегодня, слабые места, продолжить чтение, проверка уровня, цель и срок). Порядок и видимость плашек хранятся в настройках человека. Переиспользует контракт модуля из core/manifest.py и shared/engine/module/manifest.ts (module-registry) для объявления, какие данные плашка просит, и механизм data-permissions (core/userdata.py) для прав доступа — не новый механизм поверх них.
