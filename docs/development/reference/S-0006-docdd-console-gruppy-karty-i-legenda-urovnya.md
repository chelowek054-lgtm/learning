# docdd-console: группы карты и легенда уровня

Обзор — узел-группа (название, счёт, полоса состояния), между группами одна стрелка со свёрнутыми связями и подписью-числом; клик по стрелке — карточка исходных связей. Группа раскрывается на месте, путь «Все группы › X» и сводка «Опирается на / На неё опирается» ссылками, элементы со связями наружу — толстой рамкой («порты»). Выбранный элемент показывает соседей из других групп «призраками» (пунктир, подпись группы), больше 12 — свёртка в узел-группу. Обзор включается сам по порогу, переключатель «Группы/Всё» есть всегда, режим в адресе. Укладка детерминированная.
