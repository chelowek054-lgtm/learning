# Карта изменений: пачка от 2026-10-06

Общая карта-намерение на пачку задач: завели приложением, чтобы каждая
`feature`-задача не упиралась по отдельности в правило «нет подтверждённой
карты». Структур в ней нет — кода ещё нет, описывать пока нечего, и сверка
с кодом для неё не запускается (`intent: true`).

Подтвердите, когда согласны, что эти задачи меняют устройство проекта. Когда
код появится — уточните карту («Обновить карты») и снимите `intent: true`.

Задачи пачки:

- Переход на PostgreSQL 17 с AGE и pgvector
- Объектное хранилище SeaweedFS в compose и S3-клиент в бэкенде
- Пять полей цели в диалоге постановки цели
- Тест предварительных знаний и отчёт о покрытии графа
- Происхождение знаний: статус черновика, источники понятий и связей
- Разбор документа в понятия со ссылками на фрагмент
- Слияние понятий: близость по векторам и решение модели
- Инструмент загрузки учебника: API и экран администратора
- Доступ к источникам только администраторам
- Роль специалиста по областям и очередь проверки
- Поиск источников по белому списку и через веб-поиск
- Уведомление «курс готов» и «курс дополнен» с пометкой о черновике
