# Карта изменений: пачка от 2026-10-12

Общая карта-намерение на пачку задач: завели приложением, чтобы каждая
`feature`-задача не упиралась по отдельности в правило «нет подтверждённой
карты». Структур в ней нет — кода ещё нет, описывать пока нечего, и сверка
с кодом для неё не запускается (`intent: true`).

Подтвердите, когда согласны, что эти задачи меняют устройство проекта. Когда
код появится — уточните карту («Обновить карты») и снимите `intent: true`.

Задачи пачки:

- Таблицы утверждений и их источников, якоря фрагментов
- Извлечение утверждений из источника с проверкой цитаты и смещений
- Пересборка тестового графа по новой схеме
- Белый список лицензий при приёме источника
- Ссылки на источник у утверждений в API для учащегося
- Ссылки на источник в теории узла в клиенте
- Принадлежность понятия к областям
- Слияние понятий по всему графу с порогами близости
- Один запрос сверки на узел и разбор ответа
- Пул проблем для администраторов и специалистов
- Сборка теории узла из утверждений со ссылками
- Банк карточек и заданий узла с ключами ответа
- Шаг курса и проверка читают готовое, без запросов к модели
- Класс изменчивости и даты актуальности утверждения
- Плановое обновление просроченных узлов и замена утверждений
- Проверка ссылок на оригинал
- Виды решений по проблеме: сторона, условия, спорно, консенсус устарел
- «Здесь ошибка» на предложении теории
- Доверие к источнику по исходам споров и отзыв источника
- Шаги воронки без модели: дубли, качество текста, тема
- Проба моделью и уровень доверия источника
- Метрики после извлечения и карантин источника
- Словарь терминов: названия и синонимы понятий по языкам
- Английский текст и переводы утверждений, язык источника и фрагмента
- Сборка узла и банка заданий на каждый язык
- Язык изучения у человека
- Поиск источников на английском и русском
- Определение языка документа при приёме
- Словари строк ru/en в клиенте и перевод экранов
- Язык интерфейса: язык устройства по умолчанию и переключатель в профиле
- Коды ошибок сервера и уведомления на языке пользователя
