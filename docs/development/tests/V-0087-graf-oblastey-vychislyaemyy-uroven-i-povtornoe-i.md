# Граф областей: вычисляемый уровень и повторное использование

Чем проверяется: тест строит граф с несколькими областями и связями «нужно знать до» — уровень примитивности каждой совпадает с вычисленной глубиной; построение графа цели для темы, требующей уже существующей базовой области (например, «линейная алгебра» для другой цели), не создаёт её заново, а находит по ключу реестра.
