# Ручная проверка переноса дизайна: ширины, фокус, цели нажатия, сверка с макетом

Ручная проверка (не автотест — сверяется внешний вид): на 375/768/1280 px нет горизонтальной прокрутки; цели нажатия ≥44 px; у кнопок и ссылок виден фокус; каждый реализованный экран визуально сверяется с состоянием «сделано»/«частично» в макете Claude Design, в четырёх темах (светлая, тёмная, OLED, контраст).
