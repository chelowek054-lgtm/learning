# Утверждения и ссылки на место: проверка извлечения

Тест: на документе с известным текстом извлечение даёт утверждения с цитатами, смещения указывают на цитату в тексте фрагмента; утверждение с выдуманной цитатой отбрасывается. Живая проверка: на пересобранном графе у случайных 20 утверждений ссылка ведёт на верное место.
