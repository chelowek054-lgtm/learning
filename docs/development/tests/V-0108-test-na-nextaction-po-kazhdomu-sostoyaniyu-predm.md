# Тест на nextAction по каждому состоянию предмета

Автоматический тест: по отдельному кейсу на каждое состояние из таблицы (нет предмета / цель ставится / состав навыка / собирается / сбой / готова без уровня / идёт путь / повторение / цель достигнута / пауза) проверяет, что `nextAction` возвращает ожидаемый вид экрана.
