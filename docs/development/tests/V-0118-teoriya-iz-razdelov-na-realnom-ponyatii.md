# Теория из разделов на реальном понятии

Ручная проверка: открыть понятие без готовой теории в шаге курса — видны разделы (определение, применение, устройство, пример, ошибки, связи) объёмом экран-два, с пометкой источника или «не проверено»; задание шага ссылается на содержимое разделов, а не на одно summary; повторное открытие уже обработанного понятия не запускает генерацию заново (версия не растёт без правки куратором).
