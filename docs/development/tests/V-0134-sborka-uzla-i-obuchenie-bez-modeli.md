# Сборка узла и обучение без модели

Тест: сборка узла с заглушкой модели отбрасывает предложение без ссылки на утверждение; неизменный набор утверждений не вызывает повторной сборки. Тест с отключённым шлюзом модели: открытие шага, карточки и тесты по собранному узлу работают.
