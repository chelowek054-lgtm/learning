# Моя библиотека: два предмета без потери прогресса

Ручная проверка: завести второй предмет в «Моей библиотеке» — первый не сброшен (онбординг и прогресс целы); открыть каждый — виден свой «Сегодня/Путь/Прогресс»; поставить один на паузу — он не предлагает действий на «Сегодня», но остаётся в списке; очередь повторения показывает карточки обоих предметов с подписью, каким предметом карточка.
