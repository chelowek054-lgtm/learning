# «Сегодня»: сетка плашек, порядок и офлайн

Ручная проверка: на «Сегодня» видно несколько плашек, «Следующий шаг» — первая и крупнее; скрыть одну плашку и переставить другую — после перезахода настройки сохранены; для состояния «сборка идёт» / «цель достигнута» показывается плашка того же вида, что остальные; выключить сеть — плашка показывает последние известные данные с пометкой, а не падает.
