# Срок актуальности и замена утверждений

Тест: утверждение быстрого класса с истёкшей датой ставит узел на обновление; новый источник того же уровня с противоречием заменяет утверждение, старое остаётся в истории, изучавшему узел он возвращается в повторение; утверждения с разной областью применимости не дают проблемы.
