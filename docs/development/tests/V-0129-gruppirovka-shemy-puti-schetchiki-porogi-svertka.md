# Группировка схемы пути: счётчики, пороги, свёртка призраков

Тест чистой модели: свёртка связей по этапам даёт верные счётчики; связь внутри этапа в обзор не попадает; порог переключает режим; «призраки» сворачиваются после 8 соседей. Живая проверка на телефоне (390), планшете (768) и десктопе (1280): раскрыть этап, выбрать понятие, перейти по стрелке-счётчику, вернуться к обзору — ни одна линия в раскрытом этапе без выбора не пересекает больше одной колонки, обзор не больше ~6 блоков и ~10 стрелок.
