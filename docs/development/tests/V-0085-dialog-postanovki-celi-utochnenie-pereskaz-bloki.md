# Диалог постановки цели: уточнение, пересказ, блокировка построения до подтверждения

Ручной прогон на устройстве: ответ на первый вопрос → 2–4 уточняющих вопроса, часть пропущена → показан пересказ области/цели/уровня → кнопка «Построить план» неактивна до подтверждения → граф не строится без подтверждения (нет вызова построения) → после подтверждения итог передан построению. Отдельно: без сети доступна только прямая форма, без уточняющих вопросов.
