# Отчёт показывает и теряет недостающие пункты профиля

Способ: для графа, покрывающего часть профиля навыка, отчёт перечисляет непокрытые области/понятия; после того как недостающее понятие добавлено в граф, повторный отчёт его больше не показывает.
