# Проверка уровня по цепочке областей сверху вниз

Чем проверяется: сценарий с профилем, где верхний узел базовой области отмечен освоенным — проверка не спускается ниже по этой ветке; сценарий без отметок — проверка идёт по всем связанным базовым областям от сложных к простым, и путь начинается с самой нижней неосвоенной.
