# Субдомены строятся раздельно и собираются с сохранением порядка предпосылок

Ручной прогон: цель, раскладывающаяся на несколько субдоменов → показывается разбиение и принимается правка человеком → каждый субдомен строится отдельным запросом → итоговый граф содержит связи-предпосылки, проходящие через границы субдоменов → граф помечен черновиком до проверки куратором. Отдельно проверяется, что расход токенов/запросов виден и упирается в ограничение, а не растёт без предупреждения.
