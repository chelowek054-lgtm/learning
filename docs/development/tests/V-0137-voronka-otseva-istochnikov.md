# Воронка отсева источников

Тест: дубль, почти-дубль, скан с мусором и текст не по теме отклоняются без запроса к модели с причиной; источник уровня C не делает утверждение подтверждённым в одиночку; источник с высокой долей противоречий уходит в карантин.
