# Сверка утверждений и пул проблем

Тест с заглушкой модели: три добавляемых утверждения (совпадает, нейтрально, противоречит) дают ровно один запрос, одну новую ссылку, одно новое утверждение и одну проблему в пуле; спорное утверждение не попадает в сборку узла.
