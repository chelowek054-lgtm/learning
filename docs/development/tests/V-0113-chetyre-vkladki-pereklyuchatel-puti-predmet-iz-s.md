# Четыре вкладки, переключатель пути, предмет из шапки

Открыть приложение — видны «Сегодня», «Путь», «Прогресс», «Профиль»; на «Пути» переключить «Шаги/Карта»; сменить предмет из шапки на всех трёх вкладках без сброса онбординга; открыть уведомление — оно ведёт на описанный в нём экран.
