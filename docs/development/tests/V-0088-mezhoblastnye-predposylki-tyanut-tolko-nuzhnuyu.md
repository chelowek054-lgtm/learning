# Межобластные предпосылки тянут только нужную ступень

Чем проверяется: для цели «понять своими словами» курс подтягивает короткую цепочку предков узла (интуиция наклона, без производных); для цели «решить задачу» — полную цепочку с нужными понятиями; понятия базовой области вне цепочки предков в курс не попадают.
