# Аккордеон «Весь путь» на предмете с несколькими областями

Ручная проверка: открыть «Весь путь» на предмете с несколькими областями/этапами — видны группы «область — число шагов — пройдено N из M», текущий этап развёрнут, прочие свёрнуты, «Сейчас» видно сверху; свернуть/развернуть группу и перезайти — состояние сохранилось; подписи без «Черновик»/«Основа».
