# Легенда графа: верные знаки и видимость во всех видах

Тест чистой модели: для набора узлов/рёбер функция «что нарисовано → легенда» возвращает ровно присутствующие знаки с верными числами; знак без схемы не показывается; «Дерево» не показывает «своё понятие». Живая проверка: легенда видна и сворачивается во встроенной схеме и во весь экран на телефоне/планшете/десктопе, в светлой и тёмной теме; читалка экрана проговаривает строки.
