# Визуальный граф канона в админке

Три таблицы администратора заменяются визуальным графом канона: виды «Область» / «Области» / «Связи между областями», карточка узла с соседями и инлайн-правкой, правка связей прямо на схеме, поиск и фильтры для читаемости крупных областей. Готово, когда администратор правит граф канона целиком на схеме без обращения к табличным экранам.
