# Задачи на код (ML-трек)

Есть рубрика ml_code_review v1, экран задачи на код с редактором и офлайн-сохранением решения, фоновая job проверяет решение по рубрике и кладёт ошибки в error-log, задачи на код встроены в цепочку курса из практики узла. Готово, когда учащийся решает задачу на код в цепочке курса офлайн и получает оценку по рубрике.
