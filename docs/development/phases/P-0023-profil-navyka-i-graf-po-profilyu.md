# Профиль навыка и граф по профилю

По цели и уровню генерируется профиль навыка с редактированием человеком, область сопоставляется с реестром по векторной близости, для новой области автособирается граф из нескольких источников с этапами и уровнем сложности; итог — экран профиля навыка в онбординге и отчёт полноты графа против профиля. Готово, когда экран профиля навыка показывает этапы и отчёт о полноте для подтверждённой цели.
