# Воронка отсева источников: проверки без модели и проба моделью

Источник проходит дешёвые проверки без модели (дубли, качество текста, тема), затем пробу моделью с оценкой уровня доверия; после извлечения считаются метрики, и источник, не прошедший порог, уходит в карантин. Готово, когда источник с плохими метриками оказывается в карантине, а не в графе.
