# Надёжные тестовые прогоны: живые проверки и backend

Чинит два источника ложных сбоев: нестабильный вызов инструмента AI-gateway в живых проверках (grade_writing/placement/profile) и конфликт параллельных прогонов backend-тестов на общей тестовой базе. Готово, когда десять подряд прогонов живых проверок проходят без ручного повтора, а параллельные pytest-прогоны backend не дают ложных IntegrityError/«relation does not exist».
