# Быстрый контур сборки графа и «Сегодня»

Разбор крупных PDF ускорен, сборка графа разделена на быстрый контур и фоновое наполнение по областям, отметка «уже владею» сокращает наполнение, наполнение всех областей идёт параллельно с видимым статусом по каждой и подхватывает прерванную сборку; экран «Сегодня» и экран «Цель достигнута» отражают эти состояния. Готово, когда быстрый контур собирается заметно быстрее фонового наполнения и сценарий «Сегодня» верно показывает сборку, сбой и достижение цели.
