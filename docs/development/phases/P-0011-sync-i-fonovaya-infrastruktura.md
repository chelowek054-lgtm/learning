# Sync и фоновая инфраструктура

Принята и реализована стратегия конфликтов для нескольких устройств, добавлен авто-sync при offline→online и возврате из фона, push прогресса FSRS идёт с LWW по updated_at, работает инкрементальный sync (push изменённого + GET /sync/pull?since=), длинные AI-задачи уходят в фоновый воркер, сбои и расход токенов видны в мониторинге. Готово, когда два устройства одного аккаунта синхронизируются без потери данных, а фоновые задачи и их ошибки наблюдаемы.
