# Разрывы «Сегодня» и онбординга, найденные аудитом

Закрывает два пробела против уже подтверждённых требований: next-action не отражал состояние «цель ставится» (R-0057), а онбординг из пяти шагов не включал готовые экраны теста уровня и типового состава цели (R-0042/R-0055). Готово, когда «Сегодня» и онбординг покрывают эти состояния без новой логики — только встраивание уже описанного.
