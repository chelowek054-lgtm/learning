# Исправление консенсуса, жалобы и доверие к источнику во времени

У утверждения есть класс изменчивости и срок актуальности, просроченные узлы обновляются по плану с заменой утверждений через сверку; проблема по узлу получает вид решения (сторона, условия, спорно, консенсус устарел); учащийся может пометить «здесь ошибка» на предложении теории; доверие к источнику пересчитывается по исходам споров вплоть до отзыва источника. Готово, когда жалоба на утверждение проходит путь до решения и, если нужно, меняет доверие источника.
