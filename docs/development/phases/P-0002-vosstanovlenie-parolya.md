# Восстановление пароля

Код восстановления пароля доставляется на почту, хранится хешированным, запрос кода ограничен по частоте, после смены пароля старые сессии отзываются. Готово, когда сценарий «забыл пароль → письмо → новый пароль → старые сессии недействительны» проходит целиком.
