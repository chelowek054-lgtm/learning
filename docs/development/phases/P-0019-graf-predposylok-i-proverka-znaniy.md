# Граф предпосылок и проверка знаний

По цели строится граф областей со связями «нужно знать до», межобластными предпосылками и ступенями освоения; проверка освоенности идёт сверху вниз по цепочке базовых областей, а тест предзнаний даёт отчёт о покрытии графа и экран предпросмотра объёма пути. Готово, когда пользователь видит граф предпосылок, проходит тест и получает отчёт о покрытии перед началом курса.
