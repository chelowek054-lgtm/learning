# Прод-инфраструктура и релиз

Принят ADR о хостинге backend и managed Postgres, staging деплоится из main с миграциями и бэкапами, сервер отказывается стартовать с dev-секретами в staging/prod, API получает префикс /v1 с проверкой совместимости клиента, клиент переведён на EAS (dev-client, сборка, публикация в сторах, OTA). Готово, когда релиз на staging и сборка клиента через EAS проходят по документированному процессу.
