# Сборка узла: теория, задания и курс без обращений к модели, ссылки на источник

Теория узла собирается из утверждений со ссылками на источники; банк карточек и заданий получает ключи ответа; шаг курса и проверка читают готовое, не дёргая модель; тестовый граф пересобран по новой схеме; учащийся в API и в клиенте видит ссылку на источник у утверждения и в теории. Готово, когда прогон шага курса на пересобранном графе проходит без единого запроса к модели, а в теории видна кликабельная ссылка на источник.
