# Письмо IELTS/TOEFL и сквозная проверка

Есть задание ielts_writing_task1 с данными и рендерером, рубрики TOEFL integrated/independent выбираются по цели профиля. Сквозной прогон подтверждает, что письмо и ML-трек (задачи на код) работают офлайн на устройстве. Готово, когда учащийся пишет работу, получает оценку по рубрике и сценарий проверен без сети.
