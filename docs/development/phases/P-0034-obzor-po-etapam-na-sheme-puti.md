# Обзор по этапам на схеме пути

Группирует крупную схему пути в блоки этапов со счётом освоенности и стрелками-счётчиками между ними, добавляет раскрытие этапа на месте, затем сворачивает длинные связи и соседей из чужих этапов в метки и «призраков» у выбранного понятия. Готово, когда крупный граф читается по этапам вместо «паутины» связей. Ждёт дизайн-макета группировки — без него фаза не начинается.
