# Интерфейс на двух языках

Строки экранов разложены по словарям ru/en; язык интерфейса по умолчанию берётся из языка устройства и переключается в профиле; коды ошибок сервера и уведомления показываются на языке пользователя. Готово, когда переключение языка в профиле меняет все экраны и формулировки ошибок без перезапуска.
