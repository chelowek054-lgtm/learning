# Реорганизация разделов приложения

Вкладки «Курс» и «Граф» объединяются в «Путь», прогресс выносится в отдельную вкладку «Прогресс», а источники знаний и настройки разработчика переносятся в новый раздел «Куратор». Готово, когда навигация приложения отражает вкладки «Сегодня / Путь / Прогресс / Профиль» и отдельный раздел «Куратор» для админских функций.
