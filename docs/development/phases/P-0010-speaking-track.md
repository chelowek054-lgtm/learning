# Speaking track

Ответ учащегося записывается офлайн и загружается на backend, SpeechToText портирован в job transcribe фонового воркера, рубрика ielts_speaking v1 оценивает по таймингам, ошибки речи становятся карточками error-log, определена политика хранения голоса. Готово, когда записанный ответ проходит путь запись → транскрипция → оценка → карточки ошибок с учётом политики хранения.
