# Граф знаний: персональные узлы и канон

Персональные узлы можно промотировать в канон, они получают устойчивый ключ при перестроении канона, хранят версию для генерации заданий, а облегчённый список узлов доступен без загрузки полной теории. Готово, когда персональные узлы учащегося переживают перегенерацию канона и по ним строятся задания.
