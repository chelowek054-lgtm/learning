# Единица знания графа — утверждение, а не понятие

Выбор: понятие хранится как набор атомарных утверждений (определение, свойство, формула, условие, пример, типичная ошибка), у каждого — ссылки на место в источнике с дословной цитатой. Слияние, сверка, теория и задания работают с утверждениями.
Почему: сверка целых понятий не ловит расхождения в отдельных фактах; теория без ссылок на утверждения не проверяется; правило «в узле нет расхождений» формулируется только на уровне утверждений.
Альтернативы: оставить понятие единицей (дёшево, но расхождения внутри понятия не видны); хранить фрагменты без утверждений (теорию пришлось бы строить из сырых текстов при каждом открытии).
Последствия: новые таблицы утверждений и их источников; извлечение возвращает утверждения; нынешний граф — тестовый и пересобирается.
