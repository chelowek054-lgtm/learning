# AI-задачи исполняются синхронно на /sync/push (до появления воркера)

Принято 2026-07-04. Для MVP нужна очередь AI-задач, но отдельный фоновой воркер (Celery, RQ) несоразмерен объёму. Сервер обрабатывает pending-jobs пользователя синхронно внутри запроса /sync/push; результат клиент получает в том же sync через pull; для ручного запуска есть /jobs/process. Подходит для оценки текста (секунды); STT и генерация аудио (Ф4) в таймаут не уложатся — перед ними нужен ADR о воркере (P4-WS2-03). Повторов с отсрочкой при сетевом сбое самого запроса пока нет (P3-SYNC-04).
