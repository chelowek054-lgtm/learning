# Offline-first: локальная БД — источник правды для действий; LWW; один активный девайс

Принято 2026-07-04. Люди учатся без сети, а AI-оценка требует сети и стоит денег — отсутствие сети не должно мешать делать, только откладывать оценку. Решено: локальная SQLite — источник правды для ответов, повторений и очереди задач, Postgres — для AI-контента и графа; каждый тип Activity несёт флаг connectivity; AI-работа — отложенный job с клиентским UUID, идемпотентный при повторной отправке. Конфликты — LWW на уровне записи, response иммутабелен, кроме дописывания grade; один активный девайс. CRDT отвергнут как несоразмерная MVP сложность. При работе с двух устройств возможен откат интервала FSRS — принято до Ф6 (P6-SYNC-01).
