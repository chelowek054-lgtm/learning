# Перенумерация фаз: укрепление фундамента перед речью

Принято 2026-09-30. Переход на DocDD нашёл долги (клиент ни разу не на устройстве, нарушен инвариант независимости ядра, FSRS не синхронизируется, нет CI, учёт токенов отмечен сделанным без кода), которые не помещались в прежнюю Фазу 3 «речь». План перестроен в 7 фаз: Ф0 Каркас, Ф1 MVP, Ф2 Модель знаний, Ф3 Укрепление фундамента (устройство, CI, инварианты, sync, стоимость, долги графа — было частью WS0 Ф3), Ф4 Речь и рецепция (было Ф3 WS1-WS6), Ф5 Расширение обучения, Ф6 Продукт и релиз. ID задач закрытых фаз сохранены; задачи прежней Ф3 получили префикс P4.
