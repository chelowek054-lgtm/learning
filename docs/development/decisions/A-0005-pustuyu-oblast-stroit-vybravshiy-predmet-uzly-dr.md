# Пустую область строит выбравший предмет; узлы — draft до вычитки

Принято 2026-08-25. После перехода к свободному выбору предмета новый предмет оказывался тупиком: карты нет, строить канон мог только администратор. Решено: /graph/canon/build открыт любому пользователю, пока в домене нет ни одного узла; достройку и refresh делает только администратор. Построенные узлы получают status='draft' (в графе — reviewStatus, в интерфейсе — «не проверено»); куратор вычитывает и подтверждает через approve. Отвергнут вариант «строит только администратор» — новый предмет был бы тупиком.
