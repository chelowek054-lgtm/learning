# Освоенность — бета-модель с приором из предпосылок, не IRT

Принято 2026-08-23. Плейсменту нужна оценка освоенности по нескольким ответам, а калиброванных заданий нет — они генерируются. Решена бета-модель (alpha, beta) на узел плюс достигнутая ступень Блума: приор = min(оценки предпосылок) × 0.70 (у корня 0.20), сила приора — 2 виртуальных ответа; обновление байесовское по score 0..1; уверенность — по объёму свидетельств n/(n+3), а не по разбросу. IRT отвергнут — нет данных калибровки. Живой прогон нашёл и исправил два дефекта: уверенность росла от противоречащего ответа, аддитивный приор делал глубокие узлы «вероятнее известными». Переход на IRT — после накопления данных, отдельным ADR.
