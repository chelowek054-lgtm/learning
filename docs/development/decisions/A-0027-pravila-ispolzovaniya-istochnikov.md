# Правила использования источников

Решение: сначала разрешённые открытые источники (OpenStax, LibreTexts, Wikibooks, Project Gutenberg, arXiv, официальная документация), остальное — после и с пометкой; тексты источников не показываются учащимся, в теорию идёт собственное изложение с проверкой по источнику; у каждого источника хранится происхождение, его можно отозвать вместе с выведенным; автоскачивание ограничено белым списком доменов и лимитом на запрос.
Почему: владелец принял правовой риск («берём, докуда дотянемся»), правила держат его управляемым.
