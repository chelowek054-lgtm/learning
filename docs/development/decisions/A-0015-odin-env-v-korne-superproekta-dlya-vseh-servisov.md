# Один .env в корне суперпроекта для всех сервисов

Принято 2026-08-25. До этой даты было три файла окружения, и они молча расходились: ключ лежал в одном, адрес провайдера — в другом, приложение работало на заглушках без ошибки. Решено: единственный источник — корневой .env, его читают docker-compose и core/config.py (переменные окружения приоритетнее файла); learningFront переносит EXPO_PUBLIC_* в свой .env скриптом sync-env.js на хуках pre* перед каждым npm start/web; DATABASE_URL собирается из POSTGRES_*. learningFront/.env генерируется и перезаписывается — править нужно корневой файл.
