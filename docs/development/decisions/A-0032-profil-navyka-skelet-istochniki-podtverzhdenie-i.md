# Профиль навыка — скелет, источники — подтверждение и наполнение

Решение: понятия профиля сначала заводятся скелетом (черновики с этапами, уровнями, связями). Затем по каждой новой области ищутся минимум три источника из разных поставщиков (каталоги, затем веб-поиск), они разбираются и сливаются в скелет по близости; понятия, которых нет в профиле, добавляются как дополнительные черновики. Противоречия между источниками идут в конфликты слияния и решает специалист.
Последствия: граф получается полным даже при слабых источниках, а ссылки на фрагменты появляются там, где источник нашёлся; понятия без источника остаются черновиками «со слов модели».
