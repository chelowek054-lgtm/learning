# Повторение — очередь карточек, а не тип Activity

Принято 2026-09-30 (реализация — P3-SRS-01). Модули объявили три типа повторения (vocab_srs, concept_srs, srs), ни у одного нет рендерера Activity — на деле повторение уже идёт экраном карточек по srs_card, а шаг курса со срс не исполняется. Решено: типы vocab_srs/concept_srs/srs удаляются из манифестов; вместо активности srs шаг курса указывает карточку узла (concept_id), экран курса ведёт на её повторение; поле module у карточки остаётся для фильтрации и метрик. Отвергнут единый тип Activity srs_review — дублировал бы экран повторения. По завершении нужно поправить 02-logical §1, SPEC-01 и SPEC-11.
