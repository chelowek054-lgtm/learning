# Переход PostgreSQL 16 → 17 с расширениями AGE и pgvector

Решение: собрать образ Postgres 17 с AGE и pgvector, перенести данные через pg_dump с проверкой восстановления (скрипты есть), расширения создать миграцией Alembic, существующие таблицы не менять; откат — копия до перехода и прежний образ.
Почему: AGE 1.7 поддерживает PG 17 и 18, у нас PG 16. Сейчас продуктива нет, переход дешевле всего сделать сейчас. Открыто: брать ли сразу PG 18 (AGE 1.8 поддерживает только его).
