# Документация — источник правды; изменения идут по DocDD

Принято 2026-09-30. К этой дате документация разошлась с кодом и сама с собой (README vs ROADMAP по фазе 2, отмеченные сделанными, но не реализованные в коде учёт токенов и кэш генерации), требований с критериями приёмки не было. Решено вести проект по Documentation-Driven Development: цепочка трассировки 00-product→FR/NFR→SPEC→ADR→задача плана→код→проверка; поведение меняется в порядке требование→спека→план→код, устройство — ADR→архитектура→спека→план→код; у спеки обязательны критерии приёмки и раздел «Код» с расхождениями; ROADMAP только сводит статусы. Отвергнуты «оставить как есть» (расхождения копятся) и спеки в коде (не описывают будущее).
