# Expo SDK 54 ради совместимости с публичным Expo Go

Принято 2026-07-04. Проект создан на SDK 57, но публичный Expo Go в сторах отстаёт, и без своей сборки открыть проект на новом SDK на телефоне нельзя. Клиент понижен до Expo SDK 54 (React Native 0.81, React 19.1, TypeScript 5.9) для запуска в Expo Go без EAS-сборки. Отвергнут вариант «остаться на 57 и собрать dev-client» — до первого запуска потребовалась бы EAS-сборка. Перед публикацией (Ф6) клиент переходит на dev-client и EAS Build, и тогда SDK можно поднять отдельным ADR.
