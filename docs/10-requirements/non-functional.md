# Нефункциональные требования

Инварианты — это NFR, нарушение которых считается дефектом архитектуры, а не просто недоработкой. Каждый инвариант проверяется механически: командой, тестом или линтером. Инвариант без способа проверки не держится.

Последняя сверка с кодом: 2026-09-30.

---

## Инварианты системы

| ID | Инвариант | Как проверяется | Статус |
|---|---|---|---|
| **NFR-01** (INV-1) | **Offline-first.** Локальный SQLite — источник правды для повторений и ответов в offline-типах; backend — для AI-контента. Приложение полезно без сети | Сценарии offline-типов проходят в самолётном режиме (прогон на устройстве) | 🟡 держится в коде, на устройстве не проверено |
| **NFR-02** (INV-2) | **AI только через backend.** Ключей LLM/STT/TTS нет в клиенте и в git | `grep -rniE "llm_api_key\|sk-" learningFront/src` пуст; `.env*` в `.gitignore` | 🟢 |
| **NFR-03** (INV-3) | **Доменно-независимое ядро.** `learningFront/src/shared/engine` и `learningBack/core` не содержат предметного кода и не импортируют модули | `grep -rniE "languages\|ielts\|toefl\|concept\|knowledge" learningFront/src/shared/engine` пуст; `grep -rn "from modules\|import modules\|\"languages\"\|\"ml\"" learningBack/core` пуст | 🟢 (с 2026-09-30, [ADR-0019](../40-adr/0019-backend-module-registry.md)) |
| **NFR-04** (INV-4) | **Единый event log.** Каждый ответ пишется в `response`; FSRS, освоенность и метрики читают только его | Тест: ответ на шаге курса создаёт строку `response` | 🟢 |
| **NFR-05** (INV-5) | **Connectivity — флаг, а не форк.** Один клиент, доступность — свойство типа Activity | Нет файлов и веток кода «offline-версии»; `connectivity` задан у каждого `ActivityTypeDef` | 🟢 |
| **NFR-06** (INV-6) | **Версионирование.** Рубрики — данные с версиями; узлы графа версионируются; оценка помнит версию того, по чему оценивали | `rubric` PK = `(id, version)`; `assessment.concept_version`; `grade.rubricVersion` заполнен | 🟢 `grade.rubricVersion`; `response.grade` шага хранит `conceptVersion` |

## Инварианты модели знаний

| ID | Инвариант | Как проверяется | Статус |
|---|---|---|---|
| **NFR-KG-1** | Ядро не знает про граф. Граф — данные модуля `knowledge`; порядок активностей задаёт модуль | `grep -rn "concept" learningBack/core learningFront/src/shared/engine` не находит логики графа (допустима колонка `srs_card.concept_id`) | 🟢 |
| **NFR-KG-2** | Генерация заземлена на теорию узла, не «свободная» | Тест: промпт генерации содержит summary, разделы, примеры и контрпримеры узла | 🟢 |
| **NFR-KG-3** | Персональный слой лежит поверх канона (COW); канон для учащегося неизменен | Тест: оверрайд виден автору, другой пользователь видит канон | 🟢 |
| **NFR-KG-4** | Фундаментальное ядро обязательно: курс не ведёт к цели в обход непокрытого ядра | Тест: ядровые узлы в пути раньше производных | 🟢 |
| **NFR-KG-5** | Узлы версионируются; задания помнят версию | Тест: правка теории → версия +1 → кэш заданий обесценен | 🟡 персональные узлы без версии (`FR-KG-07`) |
| **NFR-KG-6** | Узлы от LLM — `draft` до подтверждения куратором | Тест: `canon/build` создаёт `status='draft'` | 🟢 |

## Качество и эксплуатация

| ID | Требование | Как проверяется | Статус |
|---|---|---|---|
| **NFR-07** | **Честные доказательства.** Статус `done` сопровождается видом проверки: live / test / build / device. Клиентская фича закрывается только после live или device | Ревью записи в плане и журнале | 🟢 правило действует |
| **NFR-08** | **Производительность повторения.** Планирование карточки FSRS < 16 мс на устройстве, без сети | Замер на устройстве | ⚪ не замерено |
| **NFR-09** | **Стоимость LLM.** Каждый запрос несёт `max_tokens`; повторная генерация берётся из кэша; модели задаются конфигом | Тест транспорта; учёт токенов (`FR-AI-05`) | 🟢 `max_tokens`, учёт токенов (`llm_usage`), кэш оценки |
| **NFR-10** | **Устойчивость транспорта к LLM.** Обрыв канала, 402 и ответ текстом вместо вызова инструмента повторяются (до 3 попыток) | Тесты `test_openai_gateway.py` | 🟢 |
| **NFR-11** | **Приватность.** Тексты и голос пользователя уходят провайдеру только для оценки; политика хранения и сроки зафиксированы **до публичного релиза и до первой записи голоса** | Документ политики в `60-operations/`; удаление по сроку | 🔴 политики нет |
| **NFR-12** | **Безопасность.** Пароли — argon2; секреты JWT и сессии админки из окружения; код восстановления хешируется до публичного релиза; CORS настраивается списком | Конфиг прода без dev-значений; ревью | 🟡 код хранится открыто (осознанно до доставки) |
| **NFR-13** | **Обязательные проверки.** Backend: `ruff format --check`, `ruff check`, `pytest`. Клиент: `npm run check` (typecheck, lint, format, tests). Проверки прогоняются в CI на каждый push | Зелёный CI | 🟡 проверки и workflow есть; зелёный прогон на GitHub не подтверждён |
| **NFR-14** | **Границы FSD.** Слой импортирует только нижние; импорт вглубь слайса запрещён | Линтер границ (`steiger` или `eslint-plugin-boundaries`) в `npm run check` | ⚪ держится на ревью |
| **NFR-15** | **Юникод в идентификаторах.** Предмет с любыми символами работает во всех запросах; сегменты URL кодируются | Тест: предмет «Теория музыки» проходит граф, плейсмент и курс | 🟢 |
| **NFR-16** | **Единый источник окружения.** Всё настраивает корневой `.env`; у сабмодулей своих `.env` нет | `ls learningBack/.env* learningFront/.env.example` пуст (кроме генерируемого `learningFront/.env`) | 🟢 |
| **NFR-17** | **Герметичные тесты.** Тесты не ходят в реальный LLM и работают на своей БД, пересоздаваемой на каждый прогон | `conftest` гасит ключ; тестовая БД `<db>_test` | 🟢 |
| **NFR-18** | **Проверено на устройстве.** Клиент запускается на iOS/Android; сквозные сценарии проходят руками | Протокол прогона в журнале ROADMAP | 🔴 ни разу не запускался на устройстве |
| **NFR-19** | **Документация не расходится с кодом.** Спеки содержат раздел «Код»; сверка документации с кодом — часть закрытия фазы | Чек в DoD фазы | 🟡 скрипты `check-invariants.sh` и `check-docs.py` есть; нужна сверка в конце фазы |
| **NFR-20** | **Совместимость клиента.** Expo SDK совместим с публичным Expo Go до перехода на dev-client/EAS | `expo start` открывается в Expo Go | 🟢 SDK 54 |
